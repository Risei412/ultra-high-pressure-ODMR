## 0. 問いの立て方

**「Ho を再現できるか」は正しい問いではない。我々は Ho を再現しない、受け取る。**

STATUS の三層構造でいえば Ho は **L0（入力）**である。したがって問うべきは:

| 問い | 答えの型 |
|---|---|
| Ho の結果のうち、**入力として受け取っている**のはどれか | 説明の対象外。前提 |
| 受け取った入力から、Ho の**別の**結果が**出てくる**のはどれか | **これが説明** |
| Ho が出していて、我々の枠組みでは**出せない**のはどれか | 限界 |
| Ho のデータのうち、**使ってはいけない**と分かったのはどれか | 正誤表 |

以下、この4分類で全項目を並べる。

## 2. 入力から**出てくる**もの（＝説明できているもの）

### H1. Fig. 5(b) の2つのドームと、そのピーク圧 ★最重要

Ho は 532 nm と 457 nm での積分 PL を圧力の関数として測り、2つのブロードな
ドームを得ている。**これは Fig. 1(e) とは別の図であり、我々のカーネルは
Fig. 1(e) だけから作られている。**

`code/repro_yield.py`:

| | pooled RMS | 相関 | ピーク圧（model/Ho）|
|---|---:|---:|---|
| 再構成カーネル | **1.0%** | **r = 1.00** | 17/17、88/88 GPa |

**図をまたいだ再現。** ドームの位置は「\(E_{\rm ZPL}(P) + p^*\hbar\omega\) が
固定レーザー線を掃過する圧力」として出る。これは説明である。

### H2. 同じことが、外部カーネル無しでも出る（E4）

さらに強い形の説明がある。単一モード Pekarian 包絡に、Ho 自身のパネルから
導いた2定数（\(\hbar\omega = 101.1\) meV、\(\Delta E_{120} = 0.464\) eV）を
入れると、**Fig. 5(b) に何もフィットせずに** pooled **1.0%**、相関 **+1.00**、
ピーク **17/17** と **89/88** GPa になる（正誤表 E4.2）。

**再構成カーネルと同じスコアである。** つまり Fig. 5(b) の2波長スライスは
「Franck–Condon 包絡 ＋ 2つの正しい定数」で完全に説明され、
Ho の完全な mode-resolved 計算を必要としない。

> **注意（E4.3）。** これは v1 を光学カーネルとして復権させない。
> 120 GPa の波長走査では内部極大が model 1 個に対しカーネル 4 個で、
> Addendum A2 の梯子は全てその4個の上に建っている。
> **包絡は再現できるが、構造は再現できない。**

### H3. 532 nm から 457 nm への運用上の切り替え

Ho は 55 GPa 以上で実際に 532 nm を諦め 457 nm に切り替えている
（Fig. 4 の測定条件）。カーネルはこの切り替えを定量化する ——
光学限界で 120 GPa の 457 nm ペナルティは ×1.04494、最適点は 440.65 nm。
**「なぜ切り替えたか」だけでなく「どこまで切り替えるべきだったか」を言う。**

### H4. 「電荷状態は ZPL に追従するので安定に保てる」の定量版

Ho の Fig. 2(c) は「励起波長を ZPL の圧力シフトに追従させれば NV⁻ の安定性は
常圧と同程度に保てる」と定性的に述べる。我々の枠組みでは、これは
**命題 P7 の系**である —— イオン化と再結合が同じ \(\sigma_{\rm abs}\) で
スケールする限り \(f_-\) は (M) 媒介であり、青色窓全域で平坦になる（0.2% 以内）。

**独立な2つの議論が同じ結論に達している。** 我々の \(f_-\) 平坦性は
モデルの artifact ではない。

### H5. Ho が計算していない層 —— 我々の付加分

Ho は自分で「これまでの高圧 NV 研究には**最適な励起条件という設計情報が
欠けていた**」と書いている。そこに載るのが我々の L1 である。

| 我々が足したもの | Ho にあるか |
|---|---|
| \(\eta = \Delta\nu/(C\sqrt{R})\) への写像 | 無い |
| 定理 M（最適集合は準位集合、多重度はパワーの階段関数） | 無い |
| 定理 G（応答は \(E=2c+s+2w\) 経由でしか \(\eta\) に入らない） | 無い |
| 定理 X（圧力による分岐交代） | 無い |
| 較正不要の遷移パワー比 \(I_k/I_c = A_{\max}/A_k\) | 無い |

**これらはカーネル非依存**なので、Ho の計算が将来更新されても壊れない。

## 3. 我々の枠組みでは出せないもの

| Ho の結果 | なぜ出せないか |
|---|---|
| \(\sigma_{\rm abs}\) そのもの（DFT + 動的 JT） | 我々は計算しない。受け取る |
| \(K^2\)(JT 活性モードの振電結合²) 0.58 → 0.97 | 実効 \(S_{\rm abs}\) に押し込めている。**未検証** |
| 発光側（\(S_{\rm em}\) 3.39 → 5.25、発光 DWF）| 使っていない。\(\eta\) は励起側で決まる |
| 輻射寿命の**非単調性** | ZPL エネルギー増大と双極子モーメント減少の競合。我々のモデルに双極子モーメントが無い |
| 高圧での ZPL **分裂**（\(^3E\) の縮退解除）| 静水圧の単一 ZPL を使っている。20–40 meV の分裂は \(\partial\lambda_{\rm opt}/\partial E_{\rm ZPL} = -182\) nm/eV で **4–7 nm** の不定性 |
| 30–90 K という測定温度の効果 | 我々の包絡も低温近似。**室温では吸収帯が広がる。未処理** |
| 光学的安定性（点滅・褪色）そのもの | \(\eta\) は定常状態のショットノイズ極限。ダイナミクスを持たない |

**このうち \(K^2\) と ZPL 分裂は \(\lambda_{\rm opt}\) に効きうる**ので、
限界として明記されている（`docs/ref_Ho2026_notes.md` §6）。

## 4. Ho のデータのうち、使ってはいけないと分かったもの

**これは「説明できない」ではなく「そもそも読めない」項目である。**
すべて自前の画素検証で見つけたもので、Ho 側の誤りではなく**図の限界**である。

| # | 内容 | 帰結 |
|---|---|---|
| **E3** | Fig. 1(e) の ZPL スパイクは**7圧力すべて軸の上端で切られている**（頂点 14.03–14.95、軸は 15）| ZPL の**高さ**は使えない。A3 の ×6.04 と \(P^*=87.9\) GPa を撤回 |
| **K2** | ZPL の見かけ FWHM が 7圧力すべてで 2.53–2.59 meV（2.4% 一定）| **描画分解能**。ZPL の**幅**も使えない。撤回分は**回復不能** |
| **K1** | 120 GPa で 3.0–3.2 eV の吸収がまだ自ピークの 72.7%。積分が 0.914 に落ちる | **402 nm はバンド端ではなく図の端**。面積量は高圧で過小評価 |
| **K3** | カーネル由来 DWF / 公表 DWF が 40 GPa まで 4%、120 GPa で **1.43 倍** | ZPL 枝の重みは 40 GPa 以下でのみカーネルから取る |
| **E1** | ZPL より低エネルギー側に**実サンプルが無い空区間**がある | その区間の値は補間であって抽出ではない |
| **E1 拡張（新規、E5.4 規則9）** | 空区間は 120 GPa 固有ではない。**ZPL が線を横切る圧力（532 nm では 92.1 GPa）から開く**。532 nm を実サンプルで挟む最後の参照曲線は **80 GPa** | \(A_{532}\) は **80 GPa まで**が抽出。100 GPa の 0.62% も 120 GPa の 0.52% と同じく補間アーティファクト |

**逆に、検証を通ったもの:** サイドバンド枝は 7圧力すべてで高さ **1% 以内**、
位置 0.015 eV 以内（E3.1）。0 GPa の ZPL 枝は **637.1 nm** に落ちる ——
パイプライン内でどこにもフィットしていない NV⁻ の ZPL である（A3）。
パネル (b)(c) は独立に digitise して \(S_{\rm JT}\) が滑らかに単調に出る（K4）。

## 5. 判定

**Ho の「結果」のうち、我々の理論が説明しているのは Fig. 5(b) である。**
それも2通りの独立な経路で、pooled 1.0%、ピーク圧一致で。これは
**別図・別観測量への外挿**なので、真の意味での説明である。

**Fig. 1(e) は説明していない。入力である。** そして 1(e) のうち
ZPL の高さ・幅・青端・40 GPa 以上の重みは**読み取れない**ことが分かっている。

**Ho が扱っていない層（\(\eta\)、梯子、ゲージ、分岐交代）が我々の寄与**であり、
それはカーネル非依存なので Ho の計算が更新されても生き残る。

> 一文でいえば ——
> **我々は Ho の吸収を説明していない。Ho の吸収が ODMR 感度に対して
> 何を意味するかを説明している。そして途中で、Ho の PL 収率曲線が
> 吸収から出ることを確認した。**

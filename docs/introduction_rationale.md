## 全体の主張(一文)

> 水素化物超伝導の決着には DAC 内部での**局所磁気イメージング**が必要で、それを担えるのは
> アンビル内 NV だけである。その律速は「ODMR が高圧で生き残るか」ではなく**感度**であり、
> 120 GPa では感度がほぼ**励起波長ひとつ**で決まる。常圧の慣習(532 nm / 405 nm)は
> どちらも物理的に破綻しており、最適は 475 nm である。

## 段落ごとの役割

### ¶1 — なぜ水素化物、なぜ 120 GPa
- Ashcroft の予言(PRL 1968 / 2004)→ H₃S 203 K @155 GPa → LaH₁₀ 250–260 K @170 GPa。
- **しかし本題は「もっと低圧の系」**:CeH₉ は 80–100 GPa で合成、1 Mbar 以下で *T*c ≤ 115 K。
  (La,Ce)H₉ は 97–172 GPa で *T*c = 148–178 K。
- → **120 GPa は「実験可能性の高い超水素化物」が集中する圧力帯**。
  ここが狙う圧力である理由の第一。極限的な低歩留まり DAC ではなく、
  よく特性の分かった DAC で届く。

### ¶2 — 証拠の問題(なぜ局所磁気測定が要るか)
- 120 GPa のキュレットは数十 µm、試料体積は pL オーダー。
  バルク磁化測定ではアンビル/ガスケットの背景から分離できない(Minkov 2022)。
- 電気抵抗の落ちだけでは超伝導の決着がつかないことは、この分野が繰り返し経験した。
- → **磁束排除の直接・局所・空間分解測定が決定実験**になった。
  (※ 特定の撤回論文を名指しせず、「抵抗だけでは足りない」という事実で押す。
  レフェリーと係争を起こさないための表現の選択。)

### ¶3 — NV がその答えである
- アンビル culet 直下に注入 → 試料から µm、試料と同じ圧力を経験。
- ODMR で**局所磁場と局所応力テンソルを同時に**取得(Doherty 2014, Hsieh/Lesik/Yip 2019)。
- 圧力到達履歴:30 GPa 級 → 130 GPa(Hilberer 2023)→ Mbar(Dai 2022, Wang 2024)→ 240 GPa(Hao 2025)。
- 最重要の応用:**CeH₉ の Meissner 効果と磁束トラップのイメージング**(Bhattacharyya, Nature 627, 73 (2024))。
  → 超伝導領域が **µm スケールで強く不均一**であることを示した。
  以降 LaH₁₀、ニッケル酸塩へ展開。

### ¶4 — 律速は感度である(この論文の存在理由)
- ¶3 の結論(不均一性)が効く:科学的中身は **マップ**(遮蔽場のテクスチャ、トラップ磁束の幾何)と
  その *T*c・圧力に沿った発展にある。
- マップ = ODMR スペクトルのラスタ。総測定時間 ∝ ピクセル数 / η_B²。
- 1 回の loading に数週間、アンビル破壊で全損。
  → **感度は figure of merit ではなく、空間分解能・視野・(P,T) 点数を買う通貨。**
- 「高圧で ODMR が生き残るか」は Ho 2026 / Huang 2025 が肯定的に決着済み。
  → 問いは「どうすれば最も感度良くできるか」に移った。

### ¶5 — 120 GPa の NV は光学的に別物(3 つのシフト)
Ho *et al.* 2026 が定量化した 3 点。**これが Introduction の物理的な核**。

| # | 現象 | 常圧 → 120 GPa | 帰結 |
|---|---|---|---|
| 1 | ZPL 青方シフト | 1.945 → ≈2.345 eV(529 nm) | **532 nm が吸収端の真上に落ちる**。青励起は好みでなく必然 |
| 2 | 電子–格子結合の強化 | S_abs 3.08 → 4.61、DWF(吸収)2.2% → 0.36% | 吸収帯が広がり重心が高エネルギー側へ。**FC 包絡の極大 = 474.8 nm** |
| 3 | 光イオン化閾値の上昇 | IP(³A₂) 2.68 → 3.06 eV、IP(³E) 1.16 → 1.63 eV | **3.06 eV = 405.2 nm**。標準の 405 nm 線が基底状態イオン化端に一致 = **使えるスペクトルの縁** |

> **注意(数値の訂正済み):** ZPL + S·ħω = 469 nm は離散フォノン数の**平均**であって、
> コードが使う連続 Pekarian 包絡の**極大**ではない。実際に `sigma_abs` を数値微分すると
> 極大は **474.8 nm**。初稿にあった「最適は吸収極大より 6 nm 赤側」という記述は
> この取り違えによる誤りで、削除済み(下記 ¶6 参照)。

### ¶6 — 3 つは同方向に働かない(だから定量的な問いになる)
- 青くする → 移動した吸収帯を追える(光子レート ↑)
- 青くする → イオン化端に近づき *f*₋ ↓、NV⁰ 蛍光でコントラスト希釈
- η ∝ Δν/(C√R):**コントラストには線形、光子レートには平方根**でしか効かない
  → どちらが勝つかは**吸収スペクトルを眺めても決まらない**。

**モデルが出した答え(重要、かつ検証可能な予言):**
イオン化端より赤側では `G_ion` の ReLU 項が消えるので、残る 2 チャンネル
(³E 経由イオン化 `a_es·σ`、再結合 `r0·σ`)が**どちらも同じ σ に比例**する。
したがって σ は *f*₋ からほぼ落ちる:463–486 nm で *f*₋ = 0.5806 → 0.5816(変動 0.2%)。
→ **固定パワーでは λ_opt は吸収極大そのものに一致する**(数値で 474.76 nm 同士が一致)。
→ `a_gs = 0` にしても λ_opt は動かない。イオン化は最適を**ずらす**のではなく、
  405 nm より青を**禁止する**という形でのみ効く。
→ この打ち消しは「a_es と r0 が同じスペクトル依存を持つ」ことに依存しており、
  NV⁰ の FC 包絡が別物である以上、**パワー依存(Part B)と校正(Part C)で崩れるはず**。
  そこが本研究の次の焦点になる。

- Ho 2026 は「ZPL のシフトを追って励起波長を調整せよ」という**定性的ガイドライン**で止まっている。
  実験者が実際にレーザーを発注するときに必要な「何 nm か、許容幅は、パワー依存はあるか」は未回答。
  ← **これが本研究のギャップ。**

### ¶7 — 本研究
- 光学入力(σ_abs、IP、S_abs、DWF)は Ho 2026 に固定、
  電荷移動レート定数と NV⁰ 背景重みのみ現象論的。
- 結果:**λ_opt = 474.8 nm @120 GPa**(= FC 吸収包絡の極大。上記の打ち消しの帰結)。
- 532 nm は ×5.2、405 nm は ×4.2 の劣化。**どちらも σ が崩壊した位置にある**のが劣化の正体で、
  405 nm の場合は加えて「これ以上青へ行けない」という境界の意味を持つ
  (405 nm では GS イオン化は全イオン化レートの 9% しか占めない ── 閾値のすぐ上だから)。
- 5% 許容帯 463–486 nm に **市販 473 nm 線が入る**(×1.001)。
- λ_opt は 0.6–0.7 nm/GPa で ZPL を追う → **圧力ごとに選び直す必要がある**。
- どのアンカーに答えが支配されるかを示し、校正実験の優先順位を決める。

## 意図的にやらなかったこと

- **撤回論文の名指しを避けた。** 「抵抗だけでは決着しない」という一般的事実で十分機能し、
  論争的な脚注を持ち込まない。
- **NV の基礎(C3v、³A₂/³E、ISC)を解説しなかった。** PRA 読者には冗長。
  必要な物理は ¶5 の表の 3 行だけで足りる。
- **感度の絶対値(nT/√Hz)を主張しなかった。** 現行モデルは相対量 η(λ)/η(λ_opt) のみ信頼できる。
  絶対値は Part C の校正後にしか出せない。Introduction でも比でしか語っていない。
- **「120 GPa で世界初」という主張をしなかった。** 240 GPa の実績が既にある(Hao 2025)。
  本研究の新規性は圧力記録ではなく**感度最適化の定量化**である、という位置取りを明示した。

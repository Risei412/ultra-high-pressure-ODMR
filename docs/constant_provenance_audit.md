# 定数の出処監査 — なぜ v1 は壊れていたのか

日付: 2026-08-28
根拠: 正誤表 E4、`code/v1_diagnosis.py`、`code/kernel_sanity_checks.py`
対象: `code/nv_model.py` の Physical anchors 全項目

---

## 0. 要旨

**文献の定数を引用していなかったのではない。全部引用してあった。**
`nv_model.py` のヘッダには出典が明記されており、そのうち2つが誤って**使われて**
いた。誤りの型は2つあり、別物である。

| 定数 | 使用値 | 正しい値 | 誤りの型 |
|---|---:|---:|---|
| \(\Delta E_{120}\) | 0.400 eV | **0.464 eV** | **片側境界を中心値として使用** |
| \(\hbar\omega\) | 65 meV | **101.1 meV** | **別の観測量からの移植** |

この2つを訂正すると、v1 は Ho Fig. 5(b) に対し pooled 39.5% → **1.0%**、
532 nm の相関 −0.51 → **+1.00**、ピーク 38/17 → **17/17** GPa となり、
両ゲートを通過する（E4)。

**そして本監査で第3の不一致が見つかった**(§4、未解決)。

---

## 1. \(\Delta E_{120}\) — 下限を中心値にした

`nv_model.py` の10行目はこう書いてある。

```
* NV- ZPL shift            dE_ZPL(120 GPa) = 0.400 eV  (>400 meV reported)
```

**注記自身が「\(>\)400 meV と報告」と書いている。** つまり Ho が公表したのは
**下限**であって値ではない。それを承知の上でコードは 0.400 を採った。

より悪いのは不確かさ伝播である(411行目)。

```
dE120  = 0.400 +/- 0.020 eV   (Ho et al., ">400 meV at 120 GPa")
dE120=0.400 + 0.020 * rng.normal(),
```

**片側境界を \(\sigma=20\) meV の対称な測定値として乱数化している。**
再構成カーネルが実際に担う値は 0.464 eV なので、これは仮定した \(\sigma\) の
**3.2 倍外**にある。モンテカルロは真値を一度もサンプルしない設計だった。

不確かさが「パラメタ化の緩み」ではなく「測定誤差」を伝播するように改修したのが
C-2 の主旨だったが、**その測定誤差の分布形そのものが誤っていた**。

---

## 2. \(\hbar\omega\) — 別の観測量からの移植

```
* Effective phonon energy  hw = 65 meV  (Kehayias et al.)
```

Kehayias らの**常圧 NV** の値を、Ho の **DFT 吸収帯**を記述する線形状の中に
入れた。

**これは圧力外挿の失敗ではない。** Ho 自身のパネルから導いた有効フォノン
エネルギーは

\[ \hbar\omega(P) = \frac{E_{\rm sideband}(P) - E_{\rm ZPL}(P)}{p^*(S_{\rm abs}(P))},
\qquad \psi(p^*+1) = \ln S \]

で、92.4 / 108.2 / 101.8 / 99.6 / 95.6 / 101.6 / 99.8 meV と**圧力依存がほぼ
無い**。**0 GPa の時点で既に 92.4 meV** であり、常圧同士で比べても 65 meV とは
合わない。持ってきていたのは初めから別の量だった(発光側 vs 吸収側、基底状態
フォノン vs 励起状態フォノン)。

**傍証。** Zotero ライブラリを検索すると **Kehayias は存在しない**。一方
Doherty (2014)、Ho (2026)、Dai (2022) はいずれも登録されている。決定的証拠では
ないが、壊れていた唯一の定数が、ライブラリに実体の無い唯一の出典だった。

---

## 3. 判別軸は「出典」ではなく「対象データで検定できるか」

「文献値をそのまま使え」が教訓ではない。**逆の例があるからである。**

```
ZPL low-pressure slope (Doherty et al., PRL 112, 047601 (2014)):
    * dE_ZPL/dP|_{P->0} = 5.75 meV/GPa   (5.5 meV/GPa measured)
```

ここでもコードは文献値(5.5)ではなく調整値(5.75)を使っている。**そしてこれは
正しかった。** 再構成カーネルの ZPL を3次スプラインで微分すると

\[ \left.\frac{dE_{\rm ZPL}}{dP}\right|_{P\to0} = 5.76\ \text{meV/GPa} \]

で、コードの 5.75 と **0.2% 一致**する。Doherty の 5.5 を使っていれば悪化した。
訂正後の v1 の ZPL 曲線が Ho と全圧力で **±3 meV** に収まるのはこのためである。

**したがって規則は「文献値を使え」ではない。**

> 外部から持ち込んだ定数が、**それを適用する対象データの中で過剰決定されて
> いないか**を先に確認し、されているなら必ず検算する。

\(\hbar\omega\) はまさに過剰決定されていた。Ho は \(S_{\rm abs}\)(パネル b)と
スペクトルそのもの(パネル e)の両方を公表しているので、整合条件
\(E_{\rm sb} = E_{\rm ZPL} + p^*(S)\hbar\omega\) を **0 GPa で一度確認するだけ**で
初日に見つかっていた。**検算できる状態にしながら検算しなかったことが本当の失敗
である。**

**同じ失敗を本作業でも繰り返した。** E4 の直前、\(p^*=S\) という連続近似で
87.9 meV を導き、導出条件そのものを検算しなかった。Pekarian の停留点は
\(p=S\) ではなく \(\psi(p+1)=\ln S\) にあり、\(S-p^*=0.51\)(ほぼ定数)。
1量子 ≈ 100 meV なので、この半量子が band maximum の 50 meV 誤差になり、
ゲート不合格を保っていた。**2回目である。**

## 4. 全アンカーの監査

`nv_model.py` の Physical anchors を、§3 の基準で分類する。

| 定数 | 使用値 | 対象データで検定できるか | 結果 |
|---|---:|---|---|
| \(\Delta E_{120}\) | 0.400 eV | 可(カーネルの ZPL 端点) | **不合格 → 0.464** |
| \(\hbar\omega\) | 65 meV | 可(パネル b + e、過剰決定) | **不合格 → 101.1** |
| \(dE_{\rm ZPL}/dP|_0\) | 5.75 meV/GPa | 可(カーネル ZPL の微分) | **合格**(5.76、0.2%) |
| \(S_{\rm abs}\) | 3.08 → 4.61 | 可(パネル b) | **合格**(3.023→4.554、差 ≤0.06) |
| 吸収 DWF | 2.2% → 0.36% | 可(パネル c) | **要調査**(§4.1) |
| IP(\(^3A_2\)) | 2.68 → 3.06 eV | 不可(Fig. 1 に無い) | 未検定 |
| IP(\(^3E\)) | 1.16 → 1.63 eV | 不可(Fig. 1 に無い) | 未検定 |
| \(C_{\rm amb}\), \(E_{\rm isc}\) | 0.2469, 0.1807 | 不可(Dai 由来、Ho と無関係) | 未検定。波長非依存なので \(\lambda_{\rm opt}\) は動かせない |
| \(a_{gs}, a_{es}, r_0, r_{bg}, w_0\), ZPL 幅 | — | — | コードが現象論的と明示済み |

### 4.1 未解決: 吸収 DWF の 120 GPa 端点

ヘッダは **2.2% → 0.36%** と記録している。パネル (c) から画素抽出した値は
**2.050% → 0.226%**。0 GPa は 7% 差で許容範囲だが、**120 GPa は 1.59 倍**
食い違う。

どちらが正しいかは未確定である。可能性は3つ。

1. ヘッダの 0.36% が本文の別の量(例えば発光 DWF、あるいは別の定義)
2. パネル (c) の抽出誤差 — ただし \(S_{\rm JT}\) が滑らかで単調に出る(K4)ので
   抽出が壊れている兆候は無い
3. ヘッダが読み違え

**現時点で DWF を使っている箇所は無い**(v3 は公表 DWF をカーネル検定にのみ使う)
ので緊急性は低いが、A3 の駆動2は DWF を使うので、原論文本文の再確認が要る。

## 5. 規則

以下を凍結記録 E4.4 の報告規則に追加する。

**R-C1 不等号で書かれた量を中心値として使わない。**
出典が `>`, `<`, `~`, 「以上」「程度」で書いている量は境界または桁である。
中心値として使わない。**乱数化は特に禁止** — 片側境界を対称分布にすると真値を
サンプルしなくなる(§1 の 3.2σ)。使わざるを得ない場合は片側分布にし、そのことを
コードのコメントに書く。

**R-C2 過剰決定を先に探す。**
外部定数を持ち込む前に、それが対象データの中で他の公表量から計算できないかを
確認する。できるなら計算し、一致を確認してから使う。一致しなければ**対象データ
側の値を採る**。

**R-C3 導出式そのものも検定対象である。**
定数を式から導くとき、その式の近似の妥当性を数値で確認する。連続近似・線形化・
漸近形は、使う範囲で誤差を評価してから使う。特に離散和の停留点を連続極限で
置き換えない(§3 の \(\psi(p+1)=\ln S\))。

**R-C4 Zotero に実体の無い出典から定数を採らない。**
少なくともコードに印を付け、R-C2 の検定を通るまで暫定扱いとする。

## 6. 結論

v1 は「単一モード Franck–Condon が高圧下で成り立たない」ために失敗したのでは
ない。**定数が2つ間違っていたために失敗した。** 訂正すれば再構成カーネルと同じ
スコアで Ho を再現する。

したがって v3 が光学カーネルを外部から受け取る根拠は、Fig. 5(b) のスコアでは
なく **E4.3 の構造** — 120 GPa の波長走査で、訂正後モデルの内部極大が 1、
カーネルが 4 (ZPL を除いて 3) であること — に置かねばならない。
Addendum A2 の準位集合・多重度梯子・遷移パワーは全てその極大の上に建っており、
単一モードはどんなパラメータでもそれを作れない。

**ゲートを通ったモデルを、通ったにもかかわらず使わない理由を述べられること。
それが本監査の帰結である。**

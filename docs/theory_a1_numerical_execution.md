| \(a^*/a_{\max}\) | \(\lambda_-\) | \(\lambda_+\) | 実測間隔 | ガウス近似 | η の縮退誤差 |

| 0.7 | 411.87 | 472.42 | 60.55 nm | 61.24 nm | 2.2e-16 |

A1 が引用する「32 nm」「60 nm」は実カーネル上で 1.5% 以内に再現する。

### P4 の機構分類表 — 完全に成立

\(\mathrm{d}\ln\Phi/\mathrm{d}\ln\Gamma_p = 1-\rho_s/(1+\rho_s)-2\rho_C/(1+\rho_C)-\rho_c/(1+\rho_c)\)
を直接評価した結果、A1 の表がそのまま再現した。

| 機構 | 単独で分岐 | \(\Gamma_p^*\) |
|---|---|---:|
| レート飽和のみ | しない | — |
| 線幅パワー広がりのみ | しない | — |
| 飽和 + 線幅広がり | する | \(\Gamma_C\) |
| コントラスト低下のみ | する | \(\Gamma_C\) |

### T4 の推定部 — 頑健

## 2. 成立しなかった / 修正を要する点

### 2.1 【重大】カーネルは単峰ではない — ZPL が第2の最適点

A1 と `theory_optima_coincidence.md` は \(A(\lambda)\) を「440.65 nm を頂点とする
平坦な単一バンド」として扱い、argmax・曲率・二重極小をすべてその前提で論じる。
**実際の再構成カーネルは 120 GPa で 4 つの極大を持つ。**

| 極大位置 | \(a/a_{\max}\) | 光学限界 penalty |
|---:|---:|---:|
| 440.64 nm | 1.000 | ×1.0000 |
| 475.55 nm | 0.660 | ×1.2306 |
| 500.19 nm | 0.277 | ×1.8994 |
| **514.46 nm(ZPL)** | **0.694** | **×1.2006** |

**ZPL(514.46 nm)の光学限界ペナルティ ×1.2006 は、473 nm の ×1.2054 と実質同一。**
514.5 nm は §7 が「実データが存在する」と明言した領域(λ ≤ 517.4 nm)の内側にあり、
しかも抽出点間隔 0.1–0.5 nm と密にサンプルされている。にもかかわらず
実験計画の候補線リスト(405/445/457/473/488/532)に一度も現れない。

帰結として、\(C/\Delta\nu\) にわずかな赤方向の傾きがあるだけで
**大域最適点は連続的に動かず ZPL へ跳ぶ**:

- A1 は「\(|\ell_G|>0.62\,\%/\mathrm{nm}\) で 5% 帯を出る」と述べる
- 数値実行では **\(\ell_G>0.268\,\%/\mathrm{nm}\) で大域最適が 514.46 nm へジャンプ**する
- 移動量は 15.6 nm ではなく 73.8 nm

閾値は A1 の主張の半分以下、移動先は約5倍遠い。P2 は局所展開なので原理的に
この跳躍を記述できない。

### 2.2 【重大】η だけでは分岐機構を同定できない

A1 は P4 から「**動かすのはコントラストである**」と結論する。単独機構の比較としては
正しいが、数値実行で次が判明した。

半飽和スケールが等しいとき、
**「飽和 + 線幅広がり」と「コントラスト低下単独」は \(\Phi(\Gamma_p)\) が厳密に一致する**
(傾きの差 1.1e-16、形状の差 4.4e-16)。同様に「飽和単独」と「線幅広がり単独」も一致する。

\[
1-\frac{\rho_s}{1+\rho_s}-\frac{\rho_c}{1+\rho_c}
\;\equiv\;
1-\frac{2\rho_C}{1+\rho_C}
\qquad(\Gamma_s=\Gamma_c=\Gamma_C)
\]

したがって \(\eta(\lambda,I)\) 曲面全体を測っても両者は区別できない。
両者を分けるのは \(\Gamma_p=1\) において

- コントラスト: 1.000(飽和+広がり) vs 0.500(コントラスト低下)
- 線幅: 1.414(飽和+広がり) vs 1.000(コントラスト低下)

すなわち **C と Δν を別々に測る以外に方法がない**。
これは v3 の実験凍結項目1(「rate, contrast, linewidth を separately 記録する」)が
利便性ではなく**論理的必然**であることの証明であり、A1 の P4 の結論文は
「分岐を起こしうるのはコントラスト低下、または飽和と線幅広がりの組であり、
両者は感度からは区別できない」と補正されるべきである。

### 2.3 κ の定義が二重になっている

P2 は \(\kappa_R\equiv-\mathrm{d}^2\ln R/\mathrm{d}\lambda^2\) と**局所2階微分**で定義する。
しかし引用値 \(8\times10^{-4}\,\mathrm{nm^{-2}}\) を再現するのは
\(\kappa=-2\ln(a)/(\lambda-\lambda_{\rm abs})^2\) という**弦(セカント)曲率**である
(§2 の表の全7点が 1% 以内で再現)。

再構成カーネルの真の局所2階微分は使い物にならない:

- 420–500 nm で範囲 [−1.12, +1.14] nm⁻²(引用値の約 1400 倍)
- 符号反転 20 回、中央値 |·| = 1.75e-4

これは青色窓の抽出点間隔が 3–10 nm(410.5, 417.7, 422.1, 428.0, 431.7, 437.7,
440.6, 447.8, 450.9, 460.7 nm …)で、その間が折れ線補間だからである。

放物線フィットで定義し直すと窓幅依存性が残る:

| フィット半幅 | κ [nm⁻²] | 2/κ [nm²] |
|---:|---:|---:|
| ±10 nm | 7.01e-4 | 2852 |
| ±15 nm | 7.61e-4 | 2628 |
| ±20 nm | 7.64e-4 | 2619 |
| ±30 nm | 7.85e-4 | 2546 |
| ±40 nm | 8.07e-4 | 2480 |

**引用値 8e-4(変換係数 2.5e3 nm²)は ±40 nm フィットに対応する。**
5% 許容帯(±15 nm)で評価すると 2628 nm² であり、A1.3 の反証条件
「測定 κ_R が 8e-4 と係数2以上ずれたら反証」は、フィット窓を指定しない限り
検定として成立しない。**A1.3 に「±40 nm 窓の放物線フィットで評価する」旨の
明記が必要。**

### 2.4 P2 の適用範囲は上下から挟まれている

| \(\ell_G\) [%/nm] | P2 予測 | 実測(バンド内) | 判定 |
|---:|---:|---:|---|
| 0.05 | 1.31 nm | 0.00 nm | 節点にピン留め |
| 0.10 | 2.63 nm | 7.16 nm | 過大 |
| 0.20 | 5.26 nm | 8.89 nm | 過大 |
| **0.40** | **10.51 nm** | **10.21 nm** | **一致(3%)** |
| 0.625 | 16.43 nm | 20.06 nm | 22% ずれ |
| 1.00 | 26.28 nm | 23.02 nm | 12% ずれ |

- **下限**: 予測変位がカーネルの節点間隔(3–10 nm)を下回ると argmax は動かない。
  \(\ell_G\lesssim0.1\,\%/\mathrm{nm}\) では P2 は検証不能。
- **上限**: \(\ell_G>0.268\,\%/\mathrm{nm}\) で大域最適が ZPL へ跳ぶ(2.1)。

**P2 が実際に使える窓は \(\ell_G\approx0.1\)–\(0.3\,\%/\mathrm{nm}\) の狭い帯だけ**である。

### 2.5 「間隔 83 nm」の行は検証不可能

A1 P3(d) と §3 の表は \(A^*/A_{\max}=0.5\) で二重極小間隔 83 nm を挙げる。
しかし再構成カーネルの青端(402 nm)における値は \(a=0.5363\) であり、
**\(a^*<0.536\) では青側の相方が データ窓の外に出る**。

- 検証可能な最大間隔: **112.6 nm**(\(a^*=0.536\)、\(\lambda_-=402\) nm)
- \(a^*/a_{\max}=0.5\) の青側解は 402 nm 未満 → 抽出データが存在しない
- さらにその領域は基底状態イオン化端 IP(³A₂)=405.2 nm の直下であり、
  A1 自身の P6 により仮定 (M) が破れる区間

つまり 83 nm の行は、**カーネル的にもデータ的にも (M) 仮定的にも根拠がない**。
0.9 行(32 nm)と 0.7 行(60 nm)のみが有効。

### 2.6 二重極小は縮退しているが対称ではない

A1 の P6 は (M) 由来の分岐を「symmetric, degenerate」と特徴づけ、
検定 T3 はその対称性に依拠して \(\lambda_\pm\) を探す。数値実行では:

| \(a^*/a_{\max}\) | 青側オフセット | 赤側オフセット | 非対称度 |
|---:|---:|---:|---:|
| 0.9 | 14.8 nm | 18.0 nm | +3.2 nm |
| 0.7 | 28.8 nm | 31.8 nm | +3.0 nm |

η の縮退は厳密(2.2e-16)だが、**波長軸上では赤側が約 3 nm 遠い**。
これはカーネルの非対称性(青側の弦曲率 8.9e-4 に対し赤側 7.1e-4)の帰結である。
5% 許容帯も同様に非対称: **[426.43, 457.90] nm**(青 14.21 / 赤 17.26)であり、
A1 の「440.65 ± 15.6 nm」という対称表記は約 3 nm の誤差を含む。

T3 を「\(\lambda_{\rm PL}\) について対称な位置を探す」手順で実施すると
最適点を取り逃がす。**T3 は \(\eta\) の等値点を探す手順として記述し直すべき。**

### 2.7 P5 の「中間パワー窓」は見かけより狭い

A1 の P5 は、パワーを上げると PL が単峰のまま感度最適が先に割れる
「中間パワー窓」が観測の勝負どころだと述べる。この窓自体は存在する
(\(\Phi\) 頭打ち \(\Gamma_p^*=0.333\) 対 PL が飽和の 10% 以内 \(\Gamma=9\) → **1.43 decades**)。

しかし**二重極小の両方がデータ窓に収まるのは \(\Gamma_p^*\) の 0.27 decades 上まで**
(パワー比にして 1.9倍)にすぎない。それを超えると青側の相方が 402 nm を割り、
窓内に残るのは赤側だけになる。さらにパワーを上げると窓内の最適点は
ZPL 近傍(514 nm 付近)へ移動する。

**観測可能な「対称な二重極小」の運用窓は約 1.9倍のパワー範囲**であり、
1.43 decades(27倍)ではない。実験のパワー刻みはこの 1.9倍窓を
分解できる密度で設計する必要がある。

## 3. 【重大】next step 文書と凍結カーネルの不整合

`docs/next_step_power_dependence_experiment.md` と `PLAN.md` は
低励起極限の推奨として次を掲げる。

> 最適波長のモデル中心値は 475.5 nm であり、市販の 473 nm レーザーは
> 感度損失約 0.2% の実質的な最適解である。

この 475.5 nm は **v1 の現象論的 Franck–Condon エンベロープ(`nv_model.py`)**
の出力であり、v3 が採用した Ho 外部カーネルの出力ではない。両者を同一条件で
実行すると:

| 圧力 | v1 FC エンベロープ | Ho カーネル(v3 凍結) | 差 |
|---:|---:|---:|---:|
| 100 GPa | 485.62 nm | 458.69 nm | +26.93 nm |
| 120 GPa | **475.51 nm** | **440.64 nm** | **+34.87 nm** |

**差 34.87 nm は 5% 許容帯の半幅(14–17 nm)の2倍以上**である。
v3 凍結カーネルで評価した候補線のペナルティ:

| 波長 | Ho カーネル penalty | 5% 帯 [426.43, 457.90] |
|---:|---:|:--|
| 440.65 nm | ×1.0000 | 内 |
| 445 nm | ×1.0038 | 内 |
| **457 nm** | **×1.0449** | **内** |
| **473 nm** | **×1.2054** | **外** |
| 475.55 nm | ×1.2306 | 外 |
| **488 nm** | **×1.5377** | **外** |
| 514.46 nm (ZPL) | ×1.2006 | 外(が 473 nm と同等) |

すなわち Stage 2 の推奨3線(457 / 473 / 488)のうち、
**凍結カーネルの 5% 帯に入るのは 457 nm だけ**であり、
「473 nm は損失 0.2%」は v1 の主張であって v3 の主張ではない。
v3 カーネルでは 473 nm の損失は **20.5%** である。

### 付随する数値的一致(要調査)

Ho カーネルの**第2極大は 475.55 nm** で、v1 の最適値 475.51 nm と
**0.04 nm で一致する**。偶然か、v1 の FC エンベロープが Ho データの
サイドバンド構造を拾っているかは本計算では判定できないが、
二つのモデルを整合させる際の手掛かりになる。

## 4. 推奨する対応

### 4.1 実験計画(next step 文書)

1. **推奨線を凍結カーネル基準で選び直す。** 5% 帯 [426.4, 457.9] nm に
   入る市販線を優先(例 430 / 440 / 445 / 457 nm)。
   457 nm は唯一そのまま使える。
2. **514.5 nm(ZPL)を候補線に追加する。** 光学限界ペナルティは 473 nm と同等
   (×1.20)で、実データが密にある領域。\(C/\Delta\nu\) が赤方向に傾く場合の
   大域最適候補であり、測らなければ 2.1 のジャンプを検証できない。
3. **475.5 nm 系の記述は「v1 モデルの結果」と明示する**か、Ho カーネル基準の
   440.65 nm に統一する。現状は同一文書群で二つの答えが併存している。
4. **パワー刻みを 1.9倍窓が分解できる密度にする**(2.7)。
   対数等間隔なら 1 decade あたり最低 6–8 点。
5. **C と Δν の分離測定は省略不可**(2.2)。η だけでは機構同定が原理的に不可能。

### 4.2 理論文書(A1)

| 箇所 | 対応 |
|---|---|
| P2 の κ | 「±40 nm 窓の放物線フィット」と定義を明記。A1.3 の反証条件も同様 |
| P2 の適用範囲 | \(\ell_G\approx0.1\)–\(0.3\,\%/\mathrm{nm}\) に限定する旨を追記 |

# 次段階: 120 GPa の波長・パワー依存測定

現行の設計事前値は、Ho の静水圧吸収カーネルから得た **約 441 nm** である。
これは低励起・固定入射パワー・波長非依存の非光学応答を仮定した値であり、
[111] 異方応力下の方向分解予測ではない。対抗仮説は
\(\alpha=0.5\)–0.95 で約502–446 nm、\(\alpha=0.6\) で488.10 nmを予測するが、
異方応力下の最適波長の直接検証ではない。

## 測定順序

1. 441 nm と488 nmで低パワーから飽和まで掃引し、`I/Ic` の絶対尺度を校正する。
2. 441、457、473、488、505、532 nm で同じ `I/Ic` 点を測る。
3. 各点で photon rate、ODMR contrast、linewidth を保存し、感度だけで機構を推定しない。
4. 利用可能なら440–505 nmを走査し、各 \(\alpha\) の最適波長を実測する。
5. 圧力標定値、軸応力、平均応力と局所 \(\alpha\) を区別して記録する。

## 成功条件

- 最適波長をデータの波長分解能と不確かさ付きで報告できる。
- \(d\lambda_{\mathrm{opt}}/d\alpha\) を求め、二仮説を判定できる。
- パワー増加で最適集合が分岐するかを事前登録したレベル集合予測と比較できる。
- 静水圧カーネルと異方応力実験の差を、未測定の光学応力結合として明示できる。
- 実測が得られるまで、追加の理論フィッティングを行わない。

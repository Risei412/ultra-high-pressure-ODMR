# 120 GPa 励起波長理論の限界と必要な実測値

## 目的

本書は、120 GPa における NV 中心 ODMR の励起波長最適化について、現在の
計算が保証する範囲と、実験による検証が必要な範囲を区別する。現行理論は実験を
開始するための設計事前値を与えるが、異方応力下の最適波長を確定するものではない。

## 静水圧で確定している設計事前値

Ho et al. の公開吸収曲線を再構成した静水圧光学カーネルに対して、次を仮定する。

- 圧力座標は静水圧 120 GPa
- 固定入射光パワー
- 低励起・未飽和領域
- 電荷収率、ODMR コントラスト、線幅、検出効率は波長に依存しない

この条件では、吸収光子数の指標は

\[
A(\lambda,P)=\lambda\,\sigma_{\mathrm{abs}}(\lambda,P)
\]

であり、感度最適波長は

\[
\lambda_{\mathrm{opt}}
=\arg\max_\lambda A(\lambda,120\ \mathrm{GPa})
\]

として求められる。現在の数値結果は次のとおりである。

| 量 | 現行の設計事前値 |
|---|---:|
| 最適励起波長 | 約 441 nm |
| 補間器上の最大位置 | 440.65 nm |
| 5% 感度許容帯 | 約 426.4–457.9 nm |
| 2% 感度許容帯 | 約 432.0–452.3 nm |
| 445 nm の感度ペナルティ | 約 0.4% |
| 457 nm の感度ペナルティ | 約 4.5% |
| **532 nm の感度ペナルティ（\(\eta\)）** | **×12.53** |
| 　同上・測定時間換算（\(\propto\eta^2\)） | ×157 |

> 感度と測定時間は 2 乗の関係にある。**この文書および対外文書では、倍率を書くときに
> どちらの量かを必ず併記すること。**（2026-09-05：§4 の表で取り違えが見つかったため）

440.65 nm の小数桁は元データの精度を表さない。青色域における抽出データの
節点間隔は約 3–10 nm なので、本文および実験計画では「約 441 nm」と報告する。

## 異方応力に対する二つの仮説

[111] 軸に沿った軸対称応力を

\[
\sigma_{xx}=\sigma_{yy}=\alpha\sigma_{zz}
\]

とする。\(\sigma_{zz}=120\ \mathrm{GPa}\) のとき、平均応力と軸方向偏差応力は

\[
P_{\mathrm{mean}}
=\frac{\sigma_{xx}+\sigma_{yy}+\sigma_{zz}}{3}
=\frac{1+2\alpha}{3}\,120\ \mathrm{GPa},
\]

\[
q
=\sigma_{zz}-\frac{\sigma_{xx}+\sigma_{yy}}{2}
=(1-\alpha)120\ \mathrm{GPa}
\]

である。\(\alpha=0.5\)–0.7 では、\(P_{\mathrm{mean}}=80\)–96 GPa、
\(q=60\)–36 GPa となる。

静水圧カーネル固定モデルは、全ての \(\alpha\) に同じ Ho の静水圧
120 GPa カーネルを用いる。このモデルでは

\[
\frac{\partial\lambda_{\mathrm{opt}}}{\partial\alpha}=0
\]

となり、全域で約 441 nm を返す。これは未校正の異方応力–光学結合をゼロと
置いた帰無仮説であり、物理的な不変性の証明ではない。

対抗仮説として、Ho の静水圧最適値を \(\alpha=1\) の絶対基準とし、Hilberer
et al. の応力応答から現象論モデルの \(\alpha\) 依存差分だけを加える：

\[
\lambda_{\mathrm{opt}}(\alpha)
=440.65\ \mathrm{nm}
+\left[\lambda_{\mathrm{opt}}^{\mathrm{NV}}(\alpha)
-\lambda_{\mathrm{opt}}^{\mathrm{NV}}(1)\right].
\]

120 GPa、300 K での条件付き推定は次のとおりである。

| \(\alpha\) | 等 \(\sigma_{zz}\) 読み（\(-0.392\)） | 等圧縮読み（\(-0.734\)） |
|---:|---:|---:|
| 0.50 | 484.63 nm | 501.50 nm |
| 0.56 | 478.92 nm | 493.38 nm |
| 0.60 | 475.18 nm | 488.10 nm |
| 0.70 | 466.08 nm | 475.36 nm |
| 0.80 | 457.30 nm | 463.23 nm |
| 0.90 | 448.83 nm | 451.67 nm |
| 0.95 | 444.71 nm | 446.10 nm |
| 1.00 | 440.65 nm | 440.65 nm |

434/769 の比を等圧縮で比較するか等 \(\sigma_{zz}\) で比較するかは未解決であり、
現時点では両方を系統幅として保持する。一般的な DAC 領域 \(\alpha=0.5\)–0.7 では
約 466–502 nm、文献比較まで含めた \(\alpha=0.5\)–0.95 では約 445–502 nm を予測する。
ただし、この差分補正は
異方応力下の吸収スペクトルを直接計算したものではなく、実験計画用の条件付き予測である。

## 文献結果との対応

- Ho et al. Fig. 1(e) の吸収カーネルは静水圧計算であり、\(\alpha=1\) の
  440.65 nm を絶対基準とする。
- Ho et al. の \(\alpha\approx0.95\) はマイクロピラー検証条件である。同論文の
  \(\alpha=1\) と 0.95 の ZPL 計算は準静水圧側の応力応答を拘束するが、
  最適励起波長を直接測定したものではない。
- Hilberer et al. の \(\alpha\approx0.56\)（通常型 DAC）と 0.95
  （マイクロピラー）の ZPL 応答比較が偏差応力係数を拘束する。

したがって文献は \(\lambda_{\mathrm{opt}}(\alpha)\) の構成要素と整合性を支持するが、
曲線全体の正しさを確定しない。特に \(\alpha=0.5\)–0.7 の最適励起波長には
新しい実測が必要である。

## 許容幅とレーザー選定

静水圧の感度曲線が形を変えず波長方向へ平行移動する近似では、\(\alpha=0.5\)–0.7
に共通する5%許容帯は、等圧縮読みで487.3–492.6 nm、等 \(\sigma_{zz}\) 読みで
470.4–483.3 nmとなる。二つの帯に共通部分はない。両正規化を含む最悪評価では、
488 nmの感度ペナルティは約8.0%であり、現時点で5%を保証する単一線はない。

この結果は「最適波長のずれ」より「固定レーザーが許容感度を満たすか」を主判定に
すべきことを示す。同時に、許容帯自体も剛体シフト近似なので実測が必要である。
図は `docs/experiment/figures/alpha_optimum_tolerance_120gpa.png` および PDF、
再生成コードは `code/fig_alpha_optimum_tolerance.py` である。

## 物理的に期待できることと保証できないこと

### 期待できること

[111] 軸対称応力では横方向の \(E\) 対称性成分が消え、NV 中心の三回回転対称性が
保たれる。このため、対称性を破る横応力と比較すると、軌道二重項分裂や
ODMR コントラスト劣化は抑制されると期待される。また、励起後の軌道・振動緩和が
ISC より十分速ければ、励起波長の記憶は失われやすい。

### 保証できないこと

[111] 軸対称応力でも、\(A_1\) 対称な平均応力および軸方向偏差応力は残る。
したがって、以下が \(\alpha\) に依存しないとは保証できない。

- ZPL エネルギーとその圧力係数
- Huang–Rhys 因子
- Debye–Waller 因子
- sideband の中心、幅、形状、振動構造
- ZPL と sideband の相対強度
- 電荷状態収率
- ODMR コントラストと線幅
- 飽和パワー

Ho et al. の結果を再現できたことは静水圧カーネルの再現性を支持するが、
異方応力下の \(\alpha\) 不変性を検証したことにはならない。

## 実験で必要な実測値

各測定点について、少なくとも次を保存する。

| 分類 | 実測値 | 用途 |
|---|---|---|
| 光学入力 | 励起波長 \(\lambda\) | 波長依存性の横軸 |
| 光学入力 | 試料位置での入射パワー | 固定パワー条件の保証 |
| 光学入力 | レーザー線幅・スペクトル | ZPL 励起帯域の評価 |
| 発光 | 検出 photon rate \(R\) | shot-noise 項の評価 |
| ODMR | コントラスト \(C\) | 感度の分子・分母分離 |
| ODMR | 線幅 \(\Delta\nu\) | 感度および応力劣化の評価 |
| ODMR | 共鳴周波数と分裂 | 局所応力・磁場の再構成 |
| 電荷状態 | NV⁻/NV⁰ のスペクトルまたは比率 | 波長依存 charge yield の評価 |
| 発光スペクトル | ZPL 位置、幅、sideband 形状 | 応力依存光学カーネルの構築 |
| 応力 | \(\sigma_{zz},\sigma_{xx},\sigma_{yy}\) または \(\alpha\) | 異方性との対応付け |
| 圧力 | 独立な圧力標定値 | 光学圧力座標との比較 |
| 温度 | NV 層近傍の温度 | hot-band・線幅・ISC の補正 |
| 空間情報 | DAC 内の測定位置 | 応力勾配と再現性の評価 |

ODMR 感度は、共通係数を除いて

\[
\eta(\lambda,\alpha)
\propto
\frac{\Delta\nu(\lambda,\alpha)}
{C(\lambda,\alpha)\sqrt{R(\lambda,\alpha)}}
\]

から直接比較する。感度だけを保存すると、吸収、コントラスト、線幅のどれが
波長依存性を生んだか識別できないため、\(R,C,\Delta\nu\) を分離して保存する。

## 最小実験プロトコル

1. \(\sigma_{zz}=120\ \mathrm{GPa}\) 付近で、実用 DAC 領域として少なくとも
   \(\alpha\approx0.5,0.6,0.7\) を用意し、可能なら文献対応点の
   \(\alpha\approx0.56,0.95\) と静水圧基準 \(\alpha=1\) を加える。
2. 各条件で 441、457、473、488、505、532 nm を同一の低入射パワーで比較する。
   可能なら ZPL 近傍の約 514.5 nm も加える(ペナルティ ×1.2006 で 473 nm と
   同等、かつ実データのある領域。A4.4、正誤表 E2.1)。
3. 波長可変光源が使える場合は、少なくとも 440–505 nm を連続走査する。
   これは静水圧仮説の約 441 nm と、偏差応力補正仮説の 446–502 nm をともに含む。
   走査範囲を静水圧 5% 帯の 426.4–457.9 nm だけに限定しない。
4. 各波長で \(R,C,\Delta\nu\)、NV⁻/NV⁰ 比、発光スペクトル、
   試料位置での実測入射パワー、NV 層近傍の温度を記録する。
5. 代表波長（少なくとも 441 nm と 488 nm）でパワー掃引し、未飽和領域と
   \(I/I_c\) を校正する。
6. ODMR、Raman、PL または他の独立手段で局所応力を評価する。
7. 同一 \(\alpha\) について複数位置・複数加圧サイクルで反復する。

設定荷重だけから \(\alpha\) を割り当てず、NV 層が実際に受ける局所応力と
波長依存データを対応付ける。

## 二仮説の判定基準

主判定量は、各 \(\alpha\) で実測した \(\lambda_{\mathrm{opt}}\) と、その傾き
\(d\lambda_{\mathrm{opt}}/d\alpha\) とする。二つの事前予測は

- 静水圧カーネル固定仮説：傾き 0、全域で約 441 nm
- 偏差応力補正仮説：\(\alpha=0.5\)–0.7 で約 475–502 nm、傾き約
  \(-131\ \mathrm{nm}/\alpha\)

である。絶対波長だけでなく傾きを使えば、共通の波長較正誤差に対して頑健に
二仮説を比較できる。

実用上は、固定レーザー線を使ったときの感度損失も別に評価し、

\[
\max_{\alpha\in[0.5,0.7]}
\frac{\eta(\lambda_{\mathrm{fixed}},\alpha)}
{\eta_{\mathrm{opt}}(\alpha)}
\le 1.05,
\qquad \lambda_{\mathrm{fixed}}\text{ は実測走査後に選定}
\]

を満たすか確認する。445 nm や 473 nm を測定前に普遍的な固定線として確定しない。
静水圧仮説では 445 nm が有利だが、偏差応力補正仮説では 473–500 nm 側が有利に
なるためである。

## 実測後に必要となるモデル改修

現行の

\[
\sigma_{\mathrm{abs}}(\lambda,P)
\]

を、少なくとも

\[
\sigma_{\mathrm{abs}}(\lambda,P_{\mathrm{mean}},q)
\]

へ拡張する。最初の校正モデルとして、例えば

\[
E_{\mathrm{ZPL}}
=E_0+k_hP_{\mathrm{mean}}+k_q q
+k_{hh}P_{\mathrm{mean}}^2+k_{hq}P_{\mathrm{mean}}q
\]

を用い、同様に Huang–Rhys 因子、Debye–Waller 因子、sideband 幅・振幅を
\(P_{\mathrm{mean}},q\) の関数として推定する。さらに必要なら、
\(C(\lambda,P_{\mathrm{mean}},q)\)、\(\Delta\nu\)、charge yield、飽和尺度も
応力依存関数へ拡張する。

平均応力をそのまま Ho カーネルの圧力座標へ代入するだけの変更は採用しない。
異方応力に対する ZPL と sideband の応答係数が未校正であり、補間カーネル上の
分岐交換を物理効果と数値効果に分離できないためである。

## 試料形態 — 試料室マイクロダイヤモンド

*2026-09-02 追記。* 本文書の他の節は **culet 注入 NV**（α をアンビル加工で選ぶ）を
前提に書かれている。試料室にマイクロダイヤモンドを置く方針では前提が変わるので、
差分をここにまとめる。

### 1. α は圧媒体が決める

culet 注入では α はアンビル形状（フラット 0.56 / マイクロピラー 0.95）で固定される。
試料室内の結晶では **α は圧媒体で決まり、媒体を替えることで掃引できる**。
アンビルを作り直さずに複数 α を取れるので、本文書「二仮説の判定基準」が要求する
\(d\lambda_{\mathrm{opt}}/d\alpha\) の測定が現実的になる。

**ただし α は仮定してはならない。** He は 11.5 GPa で固化し、120–200 GPa では
無視できない偏差応力が立つ。α は圧力とともにドリフトする。
NV 自身の \(D\) と \(E\) が α を与えるので、同一測定で記録すること。

### 2. この形態では Ho 以外のアンカーが直接当たる

| アンカー | 出典 | 試料形態 | 本方針への適用 |
|---|---|---|---|
| ZPL の曲率（線形則を棄却） | Lyapin 2018 | **micro/nano ダイヤ、He 圧媒体**、488 nm、296 K と 80 K | **直接適用** |
| コントラスト \(C(P)\) の較正 | Dai 2022 | **マイクロダイヤ**、532 nm、室温、146 GPa まで | **直接適用** |
| 光学カーネル、S_abs、DWF、IP | Ho 2026 | culet マイクロピラー、α = 0.95、30–90 K | 条件違い（温度） |

culet 注入 NV では「翻訳」が必要だった2つの較正が、この形態では試料形態まで一致する。
**これは本方針の最大の利点であり、明記すべきである。**
残る条件差は Ho の 30–90 K であり、室温運用なら吸収帯の熱広がりが入る。

### 3. 静水圧は青色優位を最大化し、コントラストを最小化する

120 GPa、単一モードモデル。\(\eta\) は相対値で、小さいほど良い。

| α | 幾何 | \(\lambda_{\mathrm{opt}}\) | \(C_0\) | 最良 \(\eta\)（相対） |
|---:|---|---:|---:|---:|
| **1.00** | **He/Ne、準静水圧** | **471.5 nm** | **2.38%** | **1.00×** |
| 0.95 | マイクロピラー culet | 475.5 nm | 2.70% | 0.81× |
| 0.80 | 劣化した PTM | 488.0 nm | 3.91% | 0.45× |
| 0.70 | 固化した PTM | 497.0 nm | 5.01% | 0.31× |
| 0.56 | フラット culet | 509.8 nm | 7.08% | 0.19× |

³E–¹A₁ ギャップが静水圧圧縮で開いて ISC が落ちるため、**静水圧は絶対感度で
5.2 倍不利**である。これは Dai が実測した「50 GPa 以上で約 1%」と同じ現象であり、
`nv_model.py` の C-3 が記述しているとおり。Huang et al. は逆に (111) アンビルの
偏差応力でコントラストが増強されると報告し、**コントラストのためには α → 0 を推奨**
している。

> **波長の主張のためには α → 1、感度のためには α → 0。この2つは正反対である。**

これは方針の欠陥ではなく、**主張をどちらに置くかの設計判断**である。
試料室マイクロダイヤは「圧力が最適波長を変える」を最もきれいに示す配置であり、
「最高感度の磁力計」を作る配置ではない。前者を主張とするなら整合している。

### 5. この形態に固有の系統誤差

1. **アンビル自身の発光。** 試料室内の微小結晶を**アンビル越しに**見るので、
   青色励起はアンビルの N3 帯（約 415 nm 吸収、415–500 nm 発光）や他の欠陥発光を
   励起する。NV 発光は 650 nm 以上なので分光的には分離できるが、背景光子は増える。
   **緑では起きにくく、青色励起に固有の問題である。**
   空セルのアンビル背景を 445 nm と 532 nm で比較する予備測定を必須とする。
2. **硬い介在物としての橋渡し。** マイクロダイヤは媒体より硬いので、bridging を
   起こすと媒体の応力状態ではなく自身の応力状態になる。粒径を小さく、量を少なくする。
3. **集光効率。** 結晶が culet と光学接触していないため、culet 注入 NV より
   集光は不利になる。
4. **温度。** Ho のアンカーは 30–90 K である。

### 6. この節が上書きする記述

- 「最小実験プロトコル」1 の「α ≈ 0.5, 0.6, 0.7 を用意し」は、アンビル加工ではなく
  **圧媒体の選択（He / Ne / Ar / 媒体なし）** で読み替える。
- 「許容幅とレーザー選定」は α = 0.5–0.7 の culet 前提である。試料室マイクロダイヤの
  準静水圧運用では §4 の表を使う。
- α を設定荷重や媒体の種類から割り当てず、**NV の \(D\) と \(E\) から実測する**。

## 120 GPa より上 — 圧力外挿の限界

*2026-09-02 追記。* 本節は α 軸ではなく**圧力軸**の限界を扱う。
コード: `code/extrapolation_bounds.py` / テスト: `code/tests/test_extrapolation_bounds.py`
文献監査: `docs/references/notes/audit_2026-09-02_six_additions.md`

本節の数値はすべて `code/extrapolation_bounds.py` が生成し、テストで固定してある。
**テストを直さずに本節の数値を書き換えないこと**（`main.tex` と同じ規約）。
再生成は `python extrapolation_bounds.py`。

### 1. コードは 120 GPa 超を「計算していない」

再構成カーネル `ho_spectrum_model.py:62-63` は 120 GPa 超で例外を送出する。
すなわち本文の 440.65 nm / 514.5 nm を produce しているモデルは、
300–400 GPa では**評価できない**。

単一モード包絡 `nv_model.py` は拒否しないが、以下がすべて 120 GPa で
クリップされていた（現在は C-8 で明示ポリシー化。既定は従来と同一）。

| 箇所 | 量 | 公開データ範囲 |
|---|---|---|
| `nv_model.py:207-210` | `Sabs`, `Sem`, `IP_A2`, `IP_E` | Ho: 0–120 GPa |
| `:257`, `:276` | 吸収 DWF、発光 DWF | Ho: 0–120 GPa |
| `:365` | `linewidth` | 現象論、140 GPa クリップ |
| `:104` | `HW = 0.065` | **圧力依存なし**（常圧値） |
| `:381` | `lambda_opt` 探索窓 | 下限 402 nm |

120 GPa より上で動いているのは `dZPL` だけであり、それも飽和形
（`Emax = 0.5697 eV`, `P0 = 99.07 GPa`）なので Emax の 70.2%（120 GPa）→
86.7%（200）→ **95.2%（300）→ 98.2%（400）**まで埋まる。

> **したがって 300 GPa 以上でコードが返す値は予言ではなく漸近値である。**
> 従来これは無警告で起きていた。

### 2. 不定性の定量

外挿則の選択（ZPL 則、アンカー継続、ħω 硬化）を振ったときの λ_opt のばらつき。

| P | Lyapin ゲート前 | ゲート後 | ゲート後の範囲 |
|---:|---:|---:|---|
| 120 GPa | 21.4 nm | **21.4 nm** | 454.1 – 475.5 nm |
| 200 GPa | 58.4 nm | **20.0 nm** | 438.9 – 458.9 nm |
| 300 GPa | 101.8 nm | **22.7 nm** | 428.1 – 450.9 nm |
| 400 GPa | 133.8 nm | **34.0 nm** | 414.0 – 448.0 nm |

### 3. Lyapin (2018) が線形 ZPL 則を棄却する

Lyapin et al., Nanosystems **9**, 55 (2018) は **He 圧媒体＝真の静水圧（α ≈ 1）**、
296 K と 80 K、**52 GPa まで**で NV⁻ ZPL を測定し、Table 1 で
\(E(P)=E_0+\alpha P+\beta P^2\) にフィットしている。

| | α (meV/GPa) | β (10⁻³ meV/GPa²) |
|---|---:|---:|
| NV⁻ 296 K | 5.81 | **−25** |
| NV⁻ 80 K | 5.57 | **−19** |
| モデル飽和形の展開 | 5.750 | −29 |

- α は `slope0 = 5.75 meV/GPa`（Doherty 2014）の**独立確認**
- β が負、すなわち **ZPL シフトが sub-linear であることはアンカー範囲の内側で
  静水圧・室温で実測済み**だった

α を Lyapin の条件（1.0）に揃えた 0–52 GPa の RMS 偏差：

| 則 | vs 296 K | vs 80 K |
|---|---:|---:|
| 飽和 | **5.8 meV** | **6.2 meV** |
| 線形 | **40.2 meV** | **39.7 meV** |

**線形則は約 6.5 倍ずれる。** しきい値を 10–35 meV のどこに置いても判定は不変。
さらに Lyapin 80 K の式を 120 GPa へ外挿すると 0.395 eV で、Ho の 0.400 eV と
1.3% 一致する。

**この文献ができないこと。** 二次式は 296 K で 116 GPa、80 K で 147 GPa で極大を取り、
それ以上では非物理的に減少する。**局所展開であって漸近形ではない。**
潰せたのは線形則のみで、飽和則の選択は依然として未決定である。

### 4. 導けるもの

**(a) ミニマックス励起波長。** ゲートを通過した則すべてに対し、各則自身の最適値からの
劣化を最小化する波長と、その最悪ケース保証。

| P | ロバスト波長 | 最悪ケース劣化 |
|---:|---:|---:|
| 120 GPa | 466.5 nm | 2.7% |
| 200 GPa | 450.5 nm | 2.7% |
| 300 GPa | 440.2 nm | 4.7% |
| 400 GPa | 432.2 nm | 10.4% |

**(b) 最適点は平坦で、平坦さは圧力にほとんど依存しない。**

| P | 5% 帯 | 2% 帯 |
|---:|---|---|
| 120 GPa | 463–488 nm（幅 24 nm） | 468–483 nm（幅 16 nm） |
| 200 GPa | 448–470 nm（幅 23 nm） | 452–466 nm（幅 14 nm） |
| 300 GPa | 440–462 nm（幅 22 nm） | 444–458 nm（幅 14 nm） |
| 400 GPa | 437–459 nm（幅 22 nm） | 441–455 nm（幅 14 nm） |

**±10 nm より細かい波長精度を追う意味はない。** 外挿の不定性（20–34 nm）は
平坦域の幅と同程度である。

**(c) イオン化の片側 bound。**

\[
\lambda_{\mathrm{opt}}(P)\;\ge\;\lambda_{\mathrm{ion}}(P)=hc/\mathrm{IP}(^3A_2)(P)
\]

405.2 / 374.2 / 341.6 / 314.1 nm（120 / 200 / 300 / 400 GPa）。
最適点が壁に押しつけられると未較正の `a_gs` に依存しなくなり、3桁振っても
0.1 nm しか動かない。

**前提条件がある。** ZPL と IP(³A₂) を**同じ法則で**外挿する場合にのみ成立する。
片方だけをクリップすると 400 GPa で 53 nm 破れる。Ho Fig. 2(c) は
「基底状態イオン化エネルギーは ZPL に密接に追従する」と述べており、混合は非物理的。
一般化すると、**クリップは全アンカーに適用するか、どれにも適用しないかのどちらかで、
選択的適用は危険である。**

**(d) パワー条件の構造。** 準位集合、多重度の梯子、\(\rho^*=1/(En-1)\)
（Dréau の \(E=3, n=2\) から 0.2）はスペクトル形状の性質であり、圧力則に依存しない。
ただし絶対 \(I_c\) は較正を要する。

### 5. 導けないもの

**(a) 感度 η そのもの。これが本当の壁である。**
Huang et al.（megabar までの ISC）は **(111) アンビルで 60 GPa 付近のコントラスト反転**
を報告している。現行の `C0(P) = C_amb·exp(−dZPL/E_isc)` は Dai の [100]/静水圧データに
較正した**単調減衰**モデルであり、これと整合しない。線幅も 140 GPa クリップの現象論である。

> **「350 GPa でどの波長を使うか」には答えられるが、
> 「そこでどれだけの感度が出るか」には答えられない。**

**(b) ħω(P)。** Ho を全文検索したが記述は無い（65 meV は常圧のレプリカ間隔として
一度出るのみ）。**ゲート後はこれが首位の不定性であり、120 GPa の 21.4 nm はまるごと
ħω 由来**で、ゲートでは 1 nm も減らない。これは外挿の問題ではなく、
**既発表の「120 GPa で約 441 nm」に乗っている未評価系統誤差**である。

**(c) 室温。** アンカーは Ho の 30–90 K である。

**(d) 120 GPa 超の IP(³A₂)、C(λ,P)、Δν(λ,P)。** 文献に存在しない（§6）。

### 6. 文献監査の結果（2026-09-02）

追加した6件のうち、**圧力依存の波長分解分光を持つのは Lyapin (2018) のみ**であった。

| 文献 | 圧力範囲 | 波長分解分光 |
|---|---|---|
| Lyapin et al. (2018) | ≤52 GPa | **あり** |
| Chen et al., arXiv:2510.21877 (LaH₁₀) | ~200 GPa | 無し（532 nm 単色） |
| Bhattacharyya et al., Nature **627**, 73 (2024) SI | ~140 GPa | 無し |
| Dailledouze et al., PRApplied **23**, 064067 (2025) | ~130 GPa | 無し |
| Wang et al., Nat. Commun. **15**, 8843 (2024) | ~130 GPa | 無し |
| Mandyam et al., Nature **651**, 54 (2026) | ~130 GPa | 無し |
| Hao et al., arXiv:2510.26605 | ~240 GPa | 無し（D(P) が 0–210 GPa で線形） |

**この分野は 532 nm を所与として扱っており、波長を変数とした高圧データは
Lyapin の 52 GPa 以外に存在しない。**

### 7. 最大の不定性は外挿ではない

```
再構成 Ho カーネル   λ_opt(120 GPa) = 440.65 nm
単一モード NVModel   λ_opt(120 GPa) = 475.5  nm
                                      -------
                                       34.9 nm
```

**完全にアンカーされた 120 GPa の内側で、2つのモデルが 34.9 nm 食い違う。**
これはゲート後の 400 GPa 外挿スプレッド（34.0 nm）より大きい。
上記 §4(a) のミニマックス波長は単一モードモデルのものであり、カーネルが正しければ
帯ごと約 35 nm 青側へずれる。

不定性を大きい順に並べる。

| 順 | 要因 | 大きさ | 解消手段 |
|---:|---|---:|---|
| 1 | **モデル選択（カーネル vs 単一モード）** | **34.9 nm** | **既存データで解決可能。新実験も新文献も不要** |
| 2 | 300–400 GPa 外挿（ゲート後） | 20–34 nm | ħω(P) の文献、または 200 GPa の実測 |
| 3 | ħω が常圧値固定 | 21 nm | 高圧 PSB レプリカ間隔 |
| 4 | α 補正の過補正疑い | ~5.6% | Hilberer 原データ |

**順位 4 の詳細。** `_alpha_factor(1.0) = 1.0559` だが、α = 0.95 のモデル（RMS 2.3 meV）
のほうが α = 1.00 のモデル（5.8 meV）より Lyapin（α ≈ 1）によく合う。
`_alpha_factor` が 5.6% 過補正している可能性がある。Hilberer の 434/769 比から
組んだ係数なので単独では結論できない。要追跡。

### 8. この節から出る運用規則

1. **120 GPa 超で単一の最適波長を引用しない。** バンドと最悪ケース保証で述べる。
2. **300–400 GPa の数値を「予言」として書かない。** コードのクリップを指摘されれば
   一行で崩れる。書けるのは bound と、法則の判別可能性である。
3. **λ_opt より先に ZPL(P) を測る。** 200 GPa の ZPL 一点が 300–400 GPa の予測を支配する。
4. **感度を主張するなら C と Δν を分離して測る。** PL だけでは Ho の追試になり、
   かつ Huang の反転と整合しない。

## 現段階の結論

静水圧 120 GPa の約 441 nm は確定した設計事前値である。異方応力については、
静水圧カーネル固定仮説と、\(\alpha=0.5\)–0.95 で約 502–446 nm を与える
偏差応力補正仮説を、同格の実験検証対象として扱う。

この段階でさらに未測定パラメータを追加して曲線を精密化しても、仮定を増やすだけで
識別力は高まらない。理論探索はここで停止し、120 GPa 付近で 440–505 nm の波長走査、
局所 \(\alpha\)、\(R,C,\Delta\nu\)、電荷状態および発光スペクトルを同時取得する。
実測または異方応力下の第一原理吸収スペクトルが得られた時点でモデルを再開する。

**圧力軸についての結論（2026-09-02 追記）。**
「300–400 GPa の励起条件は理論で導けない」は、現時点では**波長については誤り、
感度については正しい**。

- **波長は導ける。** ミニマックス解と最悪ケース保証（300 GPa で 440.2 nm / 4.7%、
  400 GPa で 432.2 nm / 10.4%）、および片側 bound \(\lambda\ge hc/\mathrm{IP}(^3A_2)\)
  として述べられる。最適点は平坦（5% 帯の幅が全圧力で約 22–24 nm）なので、
  この程度の不定性は実用上ほぼ無害である。
- **感度は導けない。** コントラストの圧力依存が未解決であり、Huang の 60 GPa
  コントラスト反転は現行の単調 `C0(P)` と整合しない。
- **そして波長側の残り不定性を減らす最善の一手は、300–400 GPa の外挿ではなく
  120 GPa のモデル不一致 34.9 nm を潰すことである。** これは新しい実験も
  新しい文献も要さない。以後の作業の第一優先とする。

## 凍結状態

静水圧層（約 441 nm、426.4–457.9 nm の 5% 帯）は凍結を維持する。
Addendum A4 の \(\alpha\) 不変性は帰無仮説としてのみ保持し、正誤表 E5 の
偏差応力補正曲線を対抗仮説として併記する。\(\lambda_{\mathrm{opt}}(\alpha)\) は
未確定であり、実測値が揃うまでこれ以上の理論フィッティングを行わない。

再開条件は、(1) 複数 \(\alpha\) での波長走査、または (2) 異方応力下の
方向分解吸収スペクトル／第一原理計算の取得とする。取得後に v4 を生成する。

**圧力軸の凍結状態（2026-09-02 追記）。**
120 GPa 超は「クリップ」を既定ポリシーとして凍結を維持する
（`NVModel(extrapolate='clip')`、従来と同一値）。線形継続は
`extrapolate='linear'` として明示的に選択したときのみ有効になり、
`'error'` は `ho_spectrum_model.py` と同じく拒否する。
Lyapin ゲートは線形 ZPL 則のみを棄却し、飽和則の選択には介入しない。

圧力軸の再開条件は、(1) 120 GPa を超える ZPL(P) の実測または文献、
(2) \(\hbar\omega(P)\) の実測または文献、(3) 120 GPa におけるカーネルと
単一モード包絡の不一致 34.9 nm の解消、のいずれかとする。
(3) は既存データで実行可能であり、他の二つを待たない。

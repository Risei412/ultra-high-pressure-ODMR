# 励起波長の実験計画

**試料形態: DAC 試料室内のマイクロダイヤモンド**（2026-09-02 改訂）

以前の版は culet 注入 NV を前提に書かれていた。試料室にマイクロダイヤモンドを
置く方針では α の決まり方と較正の当たり方が変わるので、全面的に書き直した。
背景と数値の出所は `theory_limits_and_required_measurements.md`
（特に「試料形態 — 試料室マイクロダイヤモンド」と「120 GPa より上」）にある。

---

## 1. この形態の位置づけ

### 有利な点

- **α が圧媒体で決まり、掃引できる。** アンビルを作り直さずに He / Ne / Ar /
  媒体なしで複数の α を取れる。二仮説の判定に必要な
  \(d\lambda_{\mathrm{opt}}/d\alpha\) が現実的に測れる。
- **Ho 以外の2つのアンカーが試料形態ごと一致する。** Lyapin 2018（micro/nano ダイヤ、
  He 圧媒体、488 nm）と Dai 2022（マイクロダイヤ、532 nm、室温、146 GPa）は
  どちらもこの形態で測られている。culet 注入では必要だった翻訳が要らない。
- **準静水圧では青色優位が最大になる。** 120 GPa における 532 nm のペナルティは、
  **感度 \(\eta\) で ×12.5、同一精度に要する測定時間（\(\propto\eta^2\)）で ×157** である
  （Ho カーネル、`report_120gpa_sensitivity.py` の
  `optical_limit_sensitivity_penalty` = 12.528、相対吸収レート = 0.00637）。
  「緑が死ぬ」ことを最も明瞭に示せる配置である。
  > **2026-09-05 訂正。** 旧記述は「532 nm のペナルティは ×157」とだけ書いており、
  > 感度ペナルティと読める形だった。**×157 は相対吸収光子レートの逆数、すなわち
  > \(\eta^2\) 側の量である。感度は ×12.5。** 以後、どちらの量かを必ず明記すること。
- マイクロピラー加工や FIB 注入が要らない。

### 不利な点（設計判断として受け入れる）

- **静水圧はコントラストを最小化する。** ³E–¹A₁ ギャップが開いて ISC が落ちるため、
  絶対感度はフラット culet より約 5.2 倍悪い（120 GPa で \(C_0\) が 2.4% 対 7.1%）。
  Dai の実測でも 50 GPa 以上で約 1% である。
- したがって本計画は **「圧力が最適波長を変える」を示す配置**であり、
  **「最高感度の磁力計を作る」配置ではない**。主張をそこに置くこと。

## 2. 事前値（測定前に凍結する）

| 条件 | \(\lambda_{\mathrm{opt}}\) |
|---|---|
| 準静水圧 α ≈ 1、120 GPa、カーネル | 440.65 nm |
| 準静水圧 α ≈ 1、120 GPa、単一モード | 471.5 nm |
| α = 0.8（PTM 劣化）、120 GPa | 488.0 nm |
| α = 0.7（PTM 固化）、120 GPa | 497.0 nm |

**2つのスペクトルモデルが 120 GPa で 34.9 nm 食い違っている**ことを事前に明記する。
これは外挿誤差ではなくモデル選択の差であり、本測定はこれを決着させる機会でもある。

小数桁は精度を表さない。青色域の抽出データの節点間隔は約 3–10 nm である。

## 3. 励起波長

### 運用線

| 目的 | 線 | 最悪ケースペナルティ |
|---|---|---|
| 120 GPa のみ | **457 nm** | ×1.09 |
| 120 と 200 GPa を1本で | **445 nm** | ×1.54 |
| 参考: Lyapin が使用 | 488 nm | ×2.36（120 GPa) |

### 走査

固定線1本より **440–560 nm の連続走査**が圧倒的に有利である。これ一つで
(1) \(\lambda_{\mathrm{opt}}\) の実測、(2) 34.9 nm のモデル差の決着、
(3) α 仮説の判定、の三つが同時に片付く。

固定線で組む場合は最低でも **445、457、473、488、505、532 nm**。
準静水圧では最適が 470 nm 付近まで青いので、走査範囲を 490 nm より赤側に
限定しないこと。

### 使ってはいけない線

- **405 nm。** イオン化の壁 \(hc/\mathrm{IP}(^3A_2)\) が 120 GPa でちょうど
  **405.2 nm**。吸収の問題ではなく、NV⁻ を直接イオン化する。
- **532 nm を運用線にしない。** 比較対象としては必ず測る（従来法の基準として必要）。

## 4. 必須の測定

各点で以下を**分離して**保存する。感度だけを保存すると、吸収・コントラスト・線幅の
どれが波長依存を生んだか識別できない。

1. photon rate \(R\)、ODMR コントラスト \(C\)、線幅 \(\Delta\nu\)
2. NV⁻/NV⁰ の比またはスペクトル
3. 発光スペクトル（ZPL 位置、幅、sideband 形状）
4. **\(D\) と \(E\)** — これが α の実測値になる。**α を圧媒体の種類から仮定しない**
5. 試料位置での入射パワー、スポット径、レーザー線幅
6. NV 層近傍の温度
7. 独立な圧力標定値（ルビー、ダイヤモンドラマン）

パワーは未飽和域から飽和・power broadening が見える範囲まで掃引し、
\(I/I_c\) の絶対尺度を校正する。最低 445 nm と 532 nm の2波長で行う。

---

## 5. この形態に固有の必須予備測定

1. **空セルのアンビル背景を 445 nm と 532 nm で比較する。**
   試料室内の結晶をアンビル越しに見るので、青色励起はアンビルの N3 帯
   （約 415 nm 吸収、415–500 nm 発光）や他の欠陥発光を焚く。
   NV 発光は 650 nm 以上なので分光分離はできるが、背景光子は増える。
   **緑では起きにくく、青色励起に固有の系統誤差である。** これを測らずに
   blue/green の感度比を主張しない。
2. **橋渡しの確認。** マイクロダイヤは媒体より硬いので bridging すると
   媒体ではなく自身の応力状態になる。粒径を小さく量を少なくし、
   \(E\) の分布で確認する。
3. **集光効率の較正。** culet と光学接触していないぶん不利になる。
   波長依存の検出効率（フィルタ、検出器 QE、アンビル透過）を校正する。

---

## 6. 圧力ラダー

常圧、30、60、90、120 GPa を基本とし、到達できれば 150、180、200 GPa を加える。

- **0–52 GPa**: Lyapin の実測範囲。ZPL の圧力依存を直接照合できる。
  ここで合わなければモデルではなく測定系を疑う
- 52–120 GPa: Ho と Dai の範囲。カーネルと単一モードの 34.9 nm 差を判定する主戦場
- 120 GPa 超: 外挿領域。**λ_opt より先に ZPL(P) を測る。**
  200 GPa の ZPL 1点が 300–400 GPa の予測を支配する

---

## 7. 判定

1. 実測の最小感度波長と PL 最大波長が誤差内で一致するか
2. \(\lambda_{\mathrm{opt}}(\alpha)\) の絶対値と傾き。静水圧カーネル固定仮説（傾き 0）と
   偏差応力補正仮説（約 \(-131\ \mathrm{nm}/\alpha\)）を比較する
3. **カーネル（441 nm）と単一モード（471.5 nm）のどちらが当たるか**
4. 532 nm の劣化が、吸収率だけでなくコントラスト・線幅・電荷状態を含めても維持されるか
5. ZPL(P) が飽和形か。Lyapin の二次係数（\(\beta<0\)）と整合するか

---

## 8. 停止規則

実測が得られるまで、未測定パラメータを追加する理論精密化を行わない。
`theory_limits_and_required_measurements.md` の「凍結状態」に従う。

**120 GPa 超で単一の最適波長を引用しない。** バンドと最悪ケース保証で述べる
（`code/extrapolation_bounds.py`）。

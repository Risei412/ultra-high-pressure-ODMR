## 1. 理論が現時点で凍結している主張

### 1.1 光学限界(v3 本体、再現確認済み)

120 GPa、固定入射光学パワー、低飽和、波長非依存の非光学因子を仮定すると:

| 波長 | Ho カーネル penalty | 5% 帯 [426.4, 457.9] nm |
|---:|---:|:--|
| 440.65 nm | ×1.0000 | 内 |
| 445 nm | ×1.0038 | 内 |
| **457 nm** | **×1.0449** | **内** |
| 473 nm | ×1.2054 | 外 |
| 488 nm | ×1.5377 | 外 |
| **514.5 nm(ZPL)** | **×1.2006** | 外(473 nm と同等) |

**Stage 2 の v1 推奨3線のうち、5% 帯に入るのは 457 nm だけである。**

### 1.2 分岐は E>1 で割れる(測定値)

Dréau et al. (PRB 84, 195204) の実測フィットを A2 の指数に直すと
\(c=1,\;s=0,\;w=1/2,\;n=2\) すなわち **E = 3、En = 6 ≫ 1**、\(\rho^*=1/5\)。
彼らが報告する5つのマイクロ波設定すべてで \(\rho^*\) は同一である。
**分岐条件は仮定ではなく既に測られている。** 残る未検証の仮定は (M) のみ。

### 1.3 到達可能性

\(s^* = 0.0719\,P_{\rm sat}\) なので、A2 の梯子の最下段(\(I/I_c=1.441\))は
**飽和パワーの 10.4%**。特殊な高パワー領域ではなく、
むしろ通常運転点より低い。\(s\le10\,P_{\rm sat}\) まで掃引すれば
\(I/I_c\le139\) に届く。

## 2. 推奨レーザー線(改訂)

### 2.1 主系列 — 5% 帯を張る

**430 / 440 / 445 / 457 nm**

440.65 nm を挟み、5% 帯 [426.4, 457.9] nm の内側を張る。
457 nm は市販性が高く帯の赤端にあり、v1 からの連続性も保つ。

### 2.2 必須追加 — ZPL 線

**514.5 nm**

理由は3つある。

1. 光学限界ペナルティ ×1.2006 は 473 nm(×1.2054)と**実質同一**。
2. §7 が「実データが存在する」と明言した領域(λ ≤ 517.4 nm)の内側にあり、
   抽出点間隔 0.1–0.5 nm と密にサンプルされている。
3. **A2 の多重度梯子の最下段(\(I/I_c=1.441\))を担うのが ZPL である。**
   ZPL を候補線に入れなければ、梯子の最初の段すら観測できない。

### 2.3 圧力軸のための追加

**473 / 488 / 532 nm を捨てない。**
v3 カーネルでは 120 GPa の 5% 帯の外だが、**低圧では ZPL 分岐が赤側にある**
(0 GPa で 637 nm、60 GPa で 558 nm)。A3 の分岐交代を追うには
赤側の線が要る。圧力ごとに主役が入れ替わる。

### 2.4 参照

**405 nm** — 基底状態イオン化端 IP(³A₂)=3.06 eV=405.2 nm の検証用。
A1 の P6 により、ここは (M) が破れる既知の領域である。

## 3. Stage 1 — パワー軸(単一波長)

### 3.1 測定

120 GPa、457 nm 単色でパワー掃引。各点で同時記録:

1. 試料位置での入射光学パワー(表示値ではなく実測)
2. 検出 PL レート \(R(I)\)
3. ODMR コントラスト \(C(I)\)
4. ODMR 線幅 \(\Delta\nu(I)\)
5. 可能なら試料温度指標

### 3.2 なぜ R, C, Δν の分離が省略不可か(定理化された)

A2 の定理 G により、\(\eta\) は応答を \(\Phi=C^2R/\Delta\nu^2\) 経由でしか見ない。
同じ \(E=2c+s+2w\) を持つ応答は **\(\eta\) 曲面が厳密に一致する**
(数値検証で相対差 \(<7\times10^{-16}\))。
たとえば「飽和 + 線幅広がり」と「コントラスト低下単独」は
波長スキャンを何パワーで何本行っても区別できない。

**分けるのは C と Δν を別々に測ることだけである。** v3 の実験凍結項目1 は
利便性ではなく**ゲージ固定に必要な最小限の測定**だった。

### 3.3 決定する量

- \(P_{\rm sat}\) と、そこからの \(s=P/P_{\rm sat}\) 換算
- \(R\propto I\) から 5% / 10% 外れるパワー
- \(C\) 低下が始まるパワー、\(\Delta\nu\) 広がりが始まるパワー
- **指数 \(c, s_{\rm exp}, w, n\) を個別にフィット → \(E\) と \(\rho^*\)**(検定 T7)
- \(\Phi\) の内部極大 \(\Gamma_p^*\) → \(I_c\)(検定 T4)
- 発熱による使用可能上限

### 3.4 判定

- \(E n>1\) が確認できれば分岐は起こる。Dréau の値は \(En=6\) なので
  **これが確認できない方が驚くべき結果**である。
- \(I_c\) が決まれば、§4 の梯子と §5 の交代が**波長スキャンを見ずに予言できる**。

## 4. Stage 2 — 波長軸(多重度梯子)

### 4.1 測定条件

- 同一圧力・試料位置・集光・マイクロ波・検出帯域を維持
- **波長間で入射光学パワーを等しくする**(表示値でなく試料位置で較正)
- 各波長で Stage 1 と同じ \(R, C, \Delta\nu\) を測り、同じ定義で \(\eta\) を出す
- 波長ごとのスポット径、DAC・対物・フィルタ透過率、検出効率を記録

> **v1 からの重要な変更。** 先行研究(Todenhagen & Brandt)は
> **波長ごとにパワーを個別最適化して**最大コントラストを報告している。
> これは固定パワー比較を壊す操作であり、本枠組みでは**やってはいけない**。

### 4.2 パワー刻み

A2 の段幅は ×1.05, ×1.23, ×1.93, ×1.19。
**分解するには 1 decade あたり最低 8 点の対数等間隔**が要る。
\(N=6\) の段は幅 ×1.003 しかないので**到達不能。主張しないこと。**

### 4.3 主要解析

各パワーで最適集合

\[
\Lambda_\eta(I)=\{\lambda:\ \eta(\lambda,I)=\min_\lambda\eta\}
\]

を求める。**1点とは限らない**ことに注意。

| 検定 | 内容 |
|---|---|
| **T5 梯子** | 低パワー \(R(\lambda)\) から臨界値 \(a_k\) → \(I_k/I_c=1/a_k\) を予言 → 段位置を照合 |
| **T6 普遍縮退** | 多重項の**全**メンバーの \(\eta\) を比較。厳密一致 ⟹ (M) 成立 |
| **T1 崩壊** | λ を捨てて \(\eta\) vs \(R\) をプロット。1本に乗る ⟹ (M) |

**T6 は (M) の任意精度の零検定である。** (M) は仮定ではなく検定対象として扱う
— Todenhagen は 521 nm と 575 nm で (M) の破れを実測しており、
青色窓で成立するかは未検証だからである。

## 5. Stage 3 — 圧力軸(分岐交代)【新設】

### 5.1 なぜ新設か

A3 により、**圧力は単なるパラメータではなく主変数**になった。
ZPL 分岐とサイドバンド分岐は \(S\) に対するスケーリングが異なり、
圧力が \(S\) を上げるので、\(P^*\) で大域最適が**不連続に乗り換える**。

Ho の公表データでは \(P^*=87.9\) GPa(固定光学パワー)/ 75.6 GPa(固定光子束)、
跳び幅 **71.3 nm**。

### 5.2 測定

**複数圧力で低励起の \(R(\lambda)\) スペクトルを取る。**
最低でも \(P^*\) を挟む4点、たとえば **60 / 80 / 100 / 120 GPa**。
可能なら 40 GPa を加えて低圧側の ZPL 優勢域を押さえる。

### 5.3 検定

| 検定 | 手順 | 判定 |
|---|---|---|
| **T11 駆動確認**(最優先) | 分岐間隔 \(S\hbar\omega\) の圧力依存を測る | 単調増加 ⟹ 定理 X の前件成立。一定 ⟹ 交代は起きない |
| **T8 交代** | \(\lambda_{\rm PL}(P)\) を低励起で追う | \(P^*\) で不連続に跳ぶ ⟹ 定理 X |
| **T9 分岐共存** | \(P^*\) 前後で**両方**のピークが在るか | 両方 ⟹ 交代。片方 ⟹ 分岐消失(別機構) |
| **T10 ゼロパワー縮退** | \(P\approx P^*\) で低励起のまま2波長の \(\eta\) を比較 | 等しい ⟹ A3。パワーを要する ⟹ A2 |

**T11 が最も安価で最も決定的である。** 分岐間隔は2つのピーク位置の差なので、
**絶対較正も強度較正も要らない。** 圧力を変えて2本のピーク位置を読むだけ。
これが増大しなければ前件が破れ、交代は予言されない。

### 5.4 注意 — パワー規約を明示すること

\(P^*\) は固定光学パワーか固定光子束かで **12 GPa 動く**。
どちらの規約かを書かずに \(P^*\) を引用してはならない。

### 5.5 混同してはならないもの

**457/532 の固定波長順位交差は分岐交代ではない。**
同じ Ho カーネルで 51.4 GPa に出る(交代は 87.9 GPa、36 GPa 離れている)。
固定波長交差は単峰のピークが2本のプローブの中点を通過する幾何にすぎず、
分岐構造を必要としない。v1 モデルは単峰なので原理的に交代を見られない。

## 6. Stage 4 — 電荷変換((M) の破れ)

有限パワーでの機構まで主張するには NV⁻/NV⁰ 情報が要る。

- 各波長・各パワーでの NV⁻/NV⁰ スペクトル分離
- 電荷状態分率 \(f_-(\lambda,I)\)
- 可能なら時間分解のイオン化・再結合レート
- 405 nm と 457 nm の二ビーム掃引
- レーザー照射による局所温度変化

A1 の P7 により、**電荷状態だけでは最適波長を割れない**
(イオン化も再結合も同じ σ に比例するため (M) を満たす)。
割れるのは \(\sigma_{\rm NV^0}\) が \(\sigma_{\rm NV^-}\) と**違う形**を持つときだけ。
Todenhagen の 575 nm(NV⁰ ZPL)ディップはこの候補を支持する実測例である。

- 低圧または常圧で同じ光学系を用いたパワー掃引
- **レーザー波長ごとの試料位置パワー較正**(v2 では 6 波長以上になる)
- 波長ごとのスポット径測定
- マイクロ波固定 / 各光パワーで再最適化、の両方
- 上り掃引と下り掃引でヒステリシス確認
- 長時間照射によるドリフト、NV 退色、試料変化
- **ZPL 励起時のレーザー線幅記録**(線幅が ZPL 幅より広いと実効 \(A\) が下がり、
  梯子の最下段位置がずれる)

## 8. 推奨する測定順序

1. **120 GPa、457 nm でパワー掃引**(Stage 1)→ \(P_{\rm sat}\)、\(E\)、\(\rho^*\)、\(I_c\)
2. **同圧で低励起の \(R(\lambda)\) スキャン** → 臨界値 \(a_k\) → 梯子を**予言**
3. 予言した段位置の前後で多波長 × 多パワー(Stage 2)→ T5 / T6 / T1
4. **複数圧力で低励起 \(R(\lambda)\)**(Stage 3)→ T11 を最初に、次に T8 / T9
5. 交代または縮退が見えたら NV⁻/NV⁰ 分光(Stage 4)
6. 校正結果を `code/` の該当モジュールに反映し、事後分布で再計算
7. 回帰テストと論文の該当部を校正済み数値で凍結(v4 を生成、v3 は上書きしない)

**2 と 4 は波長スキャンだけで済み、ODMR を要しない。** 最も安く、
かつ理論の前件を直接検定する。ここから始めるのが合理的である。

## 10. 現時点で論文に使用できる表現

> 120 GPa における光学限界の最適励起波長は 440.65 nm であり、457 nm は
> その 4.5% 以内にある(Ho カーネル、固定入射光学パワー、非光学因子が
> 波長非依存という仮定の下)。この仮定が成り立つかは測定対象であり、
> 感度最適波長は光子検出レートのみからは決定できない。
> 有限パワーでは最適点が単一とは限らず、吸収スペクトルの臨界値で
> 多重度が変わりうる。また圧力は零フォノン線分岐とフォノンサイドバンド分岐の
> 重みを入れ替えるため、大域最適を担う分岐が圧力で交代しうる。
> これらの予言は相対スペクトルと単一波長パワー掃引から絶対較正なしに
> 導かれ、多波長・多パワー・多圧力の測定で検定される。

**禁止事項:**

- v1 由来の 475.5 nm / 「473 nm は 0.2% 損失」を v3 の主張として書かない
- \(P^*\) をパワー規約なしに引用しない
- \(N=6\) の段(幅 ×1.003)を主張しない
- 実験校正が終わるまで、有限パワーの具体的な最適波長を確定値として扱わない
- 固定波長の順位交差を分岐交代と呼ばない

## 総評

**モデルの物理と数値実装は健全**である。乱数シードは全スクリプトで固定されており、
再現性がある。以下を実際に走らせて確認した。

| 実行 | 結果 |
|---|---|
| `pytest tests/ -q` | 66/66 pass (監査後 67/67) |
| `repro_literature.py` | 26/26 再現、1 件 OPEN(申告どおり) |
| `fig1`–`fig3` | 全て再生成でき、格納済み PNG と内容が一致 |
| `analysis_C_lambda.py` | Q1–Q3 とも完走、閾値 δ の結論に変化なし |

特に妥当性を独立に検算した点:

- 有限温度 Franck–Condon エンベロープ `_fc` の解析式。
  `exp(-S(2n̄+1))·I_ν(z)` を `exp(-S(√(n̄+1)-√n̄)²)·ive(ν,z)` に書き換える指数スケーリング、
  および `((n̄+1)/n̄)^{p/2} = exp(x/2k_BT)` の変形はいずれも厳密に正しい。
  アンダーフロー時の小引数級数フォールバックも整合。
- `_zpl_shape` の (dE120, slope0) → (Emax, P0) 逆解き。
  既定値で Emax = 0.5697 eV, P0 = 99.07 GPa、dZPL(120) = 0.400 eV、slope0 = 5.75 meV/GPa を厳密に満たす。
- `_alpha_factor(0.56) = 0.5640` vs Hilberer 実測比 434/769 = 0.5644(誤差 0.07%)。
- `eta_col` のエネルギー格子収束: `_COL_GRID = 1201` で 20001 点の値と 0.1% 以内で一致。
- `lambda_opt(120 GPa) = 473.96 nm` は `argmax σ_abs` と 0.01 nm 以内で一致(論文の中心主張)。

以下、重大度順に指摘する。**A** はコードの誤り、**B** は論文数値に効く定義・慣習の問題、
**C** は保守性・ドキュメント。A-1, A-2, A-3, C-1, C-2, C-3 は本監査で修正済み。

## A. 修正した不具合

### A-1 (重大) `fig3` の MC 帯が中心曲線を挟んでいなかった

`nv_model_power.default_randomiser_power()` が `Gamma_d`, `Gamma_d0`(絶対レート)を
直接上書きしていた。しかし `NVModelPower.__init__` の主要な修正点(docstring の
"FIXING THE INTENSITY UNIT (the Sec. V bug)")はまさに、
`Gamma_d` を「u=1 が `lambda_opt(120 GPa)` で半飽和する」条件、すなわち
`Gamma_d = s_d · σ_abs(λ_ref, 120 GPa)` に固定することであった。
中心値は `Gamma_d = 2.768` であるのに対し、MC 各ドローは `Gamma_d ≈ 0.69–1.42` と
約 1/3 になっており、**MC 内部でだけ修正前の強度単位が復活**していた。

実測した影響(n = 30, seed 11, 120 GPa):

| u | 修正前 16–84% 帯 | 中心値 | 修正後 16–84% 帯 |
|---|---|---|---|
| 0.1 | 441.7 – 455.7 nm | 461.4 nm | 453.9 – 472.0 nm |
| 1.0 | 420.4 – 428.2 nm | 434.3 nm | 431.2 – 439.3 nm |
| 10  | 405.2 – 405.8 nm | 410.8 nm | 407.9 – 415.5 nm |

修正前は u ≳ 0.1 の全域で**帯が中心曲線を含んでいない**(格納済み PNG の (b) で
帯が赤線の下側に外れているのが目視できる)。

**修正**: 無次元残差 `s_d`, `s_d0` を振るように変更。回帰テスト
`test_power_randomiser_keeps_the_saturation_reference_unit` を追加し、
`fig3` を再生成した。

### A-2 (中) `fig3(a)` のヒートマップが全面同色に飽和していた

カラースケールが `vmin=log10(1), vmax=log10(50)` の**絶対**値だったが、
η はモデルの任意単位で 120 GPa では 124–450 程度。全画素が上限にクリップされ、
パネル (a) は情報量ゼロだった(格納済み PNG も同様)。
全体最小値で規格化 (`η/η_min`) するよう変更し、軸ラベル・カラーバーも合わせた。

### A-3 (小) 回帰テストの 1 ケースが空回りしていた

`test_crossover_survives_the_charge_transfer_constants` の `{'r_0': None}` は
`r0` の打ち間違いで、直後の `None` 除去により**既定モデルの再検査**になっていた。
`{'r0': 0.5}, {'r0': 4.0}` に置換(いずれも交差圧の変化は 1e-13 GPa 未満で pass)。

## B. 未修正の指摘(論文の数値に触れるため、方針の判断を要する)

### B-1 励起の重み `I` は「光パワー一定」ではなく「光子束一定」

`README` とモデル docstring は "detected photon rate (fixed excitation power)" と書くが、
`f_minus` / `eta` はビーム重み `I = 1` をそのままレートに掛けている。
これは光子束一定であり、**光パワー一定**なら光子束は λ に比例する
(532/473 = 1.125 倍の差)。実験で固定されるのは通常レーザーパワーである。

パワー一定に直した場合の影響(実測):

| 量 | 現行(光子束一定) | パワー一定 |
|---|---|---|
| λ_opt @100 / 120 / 140 GPa | 484.1 / 474.0 / 468.4 nm | 485.7 / 475.6 / 470.0 nm |
| 532/473 交差圧 | 70.6 GPa | 72.9 GPa |
| η(532)/η(473) @120 GPa | 2.66 | 2.51 |

λ_opt の +1.6 nm は 5% 許容窓 (461.6–486.2 nm) にも MC 帯 (+3.7/−4.3 nm) にも収まり、
473 nm という推奨は変わらない。ただし論文が反証可能な予言として掲げる
**交差圧 71 GPa には +2.3 GPa の系統差**が乗る。
`fig1` の `mix = [(532, 0.5), (457, 0.5)]` のコメント "equal TOTAL optical power" も
厳密には等光子束である。

**推奨**: (a) 慣習を「光子束一定」と明記して交差圧の系統誤差 +2.3 GPa を併記するか、
(b) `R` に λ 依存の光子束因子を入れて C-8 改訂とするか、のいずれか。
(b) は golden 値を破るため凍結テストの更新を伴う。

### B-2 ZPL の Debye–Waller 線が「面積」ではなく「ピーク値」で規格化されている

`_sigma_raw` は `zpl_line = dwf · exp(-x²/2σ²)` を、単位面積のサイドバンド包絡
(`∫psb dx = ħω = 65 meV`)に**加算**している。したがって実効 DWF は
`dwf · √(2π)σ_zpl / ħω = dwf × 0.578` であり、文献値 2.2% → 0.36% は
実効 1.26% → 0.21% として実装されている。加えて実効 DWF が `zpl_width` に比例するため、
MC で `zpl_width` を ±35% 振ると**意図せず DWF も ±35% 振れる**。

影響を実測(面積規格化に直した場合):

- `lambda_opt(120 GPa)`: 473.963 nm → **473.963 nm(不変)**
- `σ_abs(532 nm, 120 GPa)`: **+10.0%**(120 GPa では ZPL が 529 nm にあり 532 nm 直近のため)
- `σ_abs(473 nm, 120 GPa)`: 変化なし

つまり中心的な答え λ_opt は影響を受けないが、**高圧での緑励起の評価が約 10% 悲観側**に
出ている(η(532) は約 5% 過大)。golden 値を破る修正なので保留した。

### B-3 120 GPa より上は外挿である

`Sabs`, `Sem`, `IP_A2`, `IP_E`, DWF は `np.clip(P, 0, 120)` で 120 GPa 以上凍結される一方、
`dZPL` は飽和則で伸び続け、`linewidth` は 140 GPa で clip される。
R9 (140 GPa), R10 (150 GPa), `test_headline_numbers` の 150 GPa 判定、`fig1`/`fig2` の
140 GPa までの曲線は、いずれも**アンカーの範囲外の外挿**に依存する。
物理的には無理のない扱いだが、図・表に外挿域を明示するか、120 GPa 以上を
破線で描くことを推奨する。
副作用として、405 nm の一光子イオン化項 `ReLU(Eγ − IP_A2)` は
IP_A2(120 GPa) = 3.06 eV = 405.2 nm でちょうど閉じ、120 GPa 以上では常にゼロになる
(`fig2(b)` の "ionisation edge" が 405 nm に貼り付くのはこのため)。

### B-4 `NVModelPower` は `eta_col`(集光効率)を使っていない

`NVModelPower.eta_u` は `R = f·n_E` で、親クラスの `collection` フラグを継承しながら
一切参照しない。`eta_col` は波長非依存なので λ_opt(u) には影響しないが、
`NVModel.eta` と `NVModelPower.eta_u` の η は**互いに定数倍ずれている**。
両者の絶対値を並べる場合は注意が必要。フラグを明示的に無視する旨のコメント、
または `R *= self.eta_col(P)` の追加を推奨する。

### B-5 `_zpl_shape` の縮退時フォールバックが黙って外れる

`rhs = dE120/(120·slope0) ≥ 1`(飽和解なし)の場合、`P0 = 1e6` の線形則に落ちるが、
このとき `dZPL(120) ≠ dE120` となりアンカーを満たさない。既定分布では ~7σ の事象で
実際には到達しないが、警告なしに主張が崩れる経路である。`warnings.warn` を推奨。

### B-6 軽微

- `fig1`: `xover = P[np.argmax(etaB < etaG)]` は交差がない場合に黙って 0 を返す。
- `fig1(a)`: 注釈 "ref. Ho et al. 70 GPa" が凡例と重なる(格納済み PNG で確認)。
- `analysis_C_lambda.py` の `KB_meV = 0.08617333262*1000/1000` は冗長(値は正しい)。
- `check_consistency()` は print するだけで assert がない(実質デモ)。

## C. ドキュメント・保守性(修正済み)

### C-1 `requirements.txt` が実際の依存と不整合(修正済み)

`nv_model.py` と `tests/` は `np.trapezoid` を使う。これは **numpy 2.0 以降**の API で、
`numpy>=1.23` の指定では `AttributeError` になる。`pytest` も未記載だった。
→ `numpy>=2.0`, `pytest>=7.0` に修正。

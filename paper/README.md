# Manuscript

`main.tex` is the current Physical Review Applied design manuscript.
Its early results show how the conditional blue-laser optimum changes with
stress ratio alpha, alongside the hydrostatic reference and legacy baseline.

Build from this directory:

```powershell
.\build.cmd
```

The generated PDF and intermediate files are written to `build/`. Manuscript
figure PDFs are stored in `figures/` and are regenerated by the corresponding
scripts in `../code/`.

Superseded manuscript sources are stored in `../archive/manuscripts/`.

The alpha-dependent optimum/tolerance figure is generated by
`python code/fig_alpha_optimum_tolerance.py` from the repository root and
stored in `../docs/experiment/figures/`. The G/M/X theory manuscript is
retained as `../archive/manuscripts/main_theory_GMX_20260906.tex`.

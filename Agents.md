\## Manuscript build



The main manuscript is:



main\_pla.tex



After editing any manuscript-related `.tex` file, run:



build.cmd



A manuscript-editing task is not complete until compilation succeeds.



If compilation fails:

1\. inspect the LaTeX error,

2\. fix errors caused by the edit,

3\. run build.cmd again.



Do not change scientific claims, numerical values, equations, or citations merely to make compilation succeed.
